# bc-11474.1.0 cross-model check (Brutus, 2026-10-08)

Released production set, build `b-metamem-rel3` (main at 4f530438). The patches promoted in this release were first
measured on Qwen3.8 Flash-Next only. This run repeats them on a second prompt, on Qwen3.8-27B and on Gemma.
Script: `tools/lab/flash-next/cross-model-rel.sh`.

## Qwen3.8-27B Q8_0, dual 7900 XTX tensor split, built-in MTP (`prod27b-ab.sh`, same binary on both arms)

Two ABBA repeats (4 runs per arm). Greedy text identical in every arm (md5 c53f194f7b40 at 10K, 8f4e26c44469 at 32K).

| Mechanism | Depth | On | Off | Result |
|---|---|---|---|---|
| 1348 deferred catch-up, prefill t/s | 10240 | 1281.6, 1300.3, 1299.5, 1298.5 | 1279.6, 1279.2, 1281.3, 1282.7 | about +1%, ranges touch |
| 1348 deferred catch-up, prefill t/s | 32768 | 1254.6, 1254.1, 1254.8, 1253.3 | 1244.1, 1243.9, 1243.7, 1244.2 | +0.8%, complete separation |
| 1321/1322 look-ahead, decode t/s | 10240 | 52.3, 52.2, 52.3, 52.4 | 74.0, 74.3, 74.2, 74.3 | **-30%** |
| 1321/1322 look-ahead, decode t/s | 32768 | 55.6, 55.6, 55.5, 55.9 | 72.7, 72.8, 73.2, 72.9 | **-24%** |

Decode with 1348 on or off: 71.1-74.4 vs 74.2-74.6 at 10K (first run of the session low), 72.8-73.5 vs 72.8-73.4 at 32K.
`BIGCHERRY_PATCH_HIT patch=1348_mtp_deferred_catchup` present. With look-ahead on, acceptance moves from 177/310 to
171/334 (10K) and 181/293 to 180/297 (32K) and each step costs 57.6 ms instead of 43.6 ms: the draft runs on the same
two cards as the target here, so the look-ahead draft competes with the target's verify.

**Consequences.** 1348 has no regression on a second model, which supports its default-on setting. Look-ahead must
stay a Flash-Next profile switch (`BIGCHERRY_MTP_AHEAD = 1` in `src/profile/flashnext.ini`, where the draft has its
own card) and must not become a build default.
