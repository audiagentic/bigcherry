# llama.cpp on BigCherry: overview

llama.cpp is BigCherry's primary serving engine: upstream's own tree, kept
current via `engines/llamacpp/patches/` (anchored, package-only edits) and
`src/` (new files, mirroring the upstream layout). See the top-level
`README.md` for the two-bucket overlay model, and
`docs/reference/patches/PATCH_SYSTEM.md` / `PATCH_AUTHORING.md` for the
package layout, lifecycle states, and how to author or validate a patch.

llama.cpp's "enhancement" unit is the patch package itself
(`engines/llamacpp/patches/<id>/`) — there is no separate `components/`
directory the way radiance has one. Each patch package carries its own
`README.md` per `docs/reference/DOC_STRUCTURE.md`'s Summary/Outcome/Detail
shape; the table below is regenerated from those docs.
