# libr3 baseline, targets and measurement for native gfx1100 kernels

## Description

Fix the starting numbers, the targets and the way every later RR item is measured, so each native kernel is judged the same way. State on 2026-10-10 (radiance 1.3.0 89cee7c, ROCm 7.2.4, one RX 7900 XTX, MXFP4 Qwen3.8-27B, drafter off, bf16 KV, ctx 8192): all-emulated libr3 7.0-7.7 tok/s decode; native loop with fp8 widened in the K loop 8.8-8.9; one-fragment form staging bf16 18.8-18.9 (commit d105d8f7). Per-op profile of that build: MXFP4 gemm_nt_q is 88% of device time (38% N=34816 K=5120 gate/up at 332 us/call, 20% N=5120 K=17408 down, 16% N=16384 K=5120, 11% N=5120 K=6144, 4% N=12288 K=5120), logits_gemm bf16 2.8%. radiance on the R9700: 37-38 tok/s decode without drafter, prefill 3,090-3,150 tok/s. hipfire's published figures for the same model (MQ4, its own kernels): XTX prefill 3,021.5 tok/s and MTP decode 87.5; R9700 5,166.1 and 68.0. Targets for one XTX: decode without drafter >= 40 tok/s (above the R9700; memory-rate ceiling is about 45 at 650 GiB/s over 14.15 GiB of weights), prefill >= 2,500 tok/s at 8K (hipfire reaches 3,021 with a different weight format). Prefill on the XTX is not expected to pass the R9700: it is matrix-compute-bound and hipfire's own kernels show the R9700 71% ahead.

## Steps

1. Add a prefill measurement to tools/lab/radiance/libr3-serve-smoke.sh: one request with a long prompt (8K tokens of fixed text, max_tokens 1), report prompt tok/s from the server's request line. 2. Add a repeat count (three runs) and print the median for decode and prefill. 3. Add PROFILE=1 as shorthand for EXTRA=--profile-ops and print the per-op table aggregated by op and shape (the awk used on 2026-10-10 becomes tools/lab/radiance/profile_ops.py). 4. Record the baseline with the current build: decode, prefill at 8K, per-op shares for decode and for prefill separately. 5. Record the same three numbers for radiance's own libr4d on the R9700 with the same script (GPU=2, kernels libr4d). 6. Write the baseline table into engines/radiance/kernels/README.md.
