# Apply the CMake job cap to Radiance component and test builds

## Notes



## Findings

The manual CI trial exports CMAKE_BUILD_PARALLEL_LEVEL and the campaign builder honors it by omitting bare -j. Runtime bundle build helpers and the bump adapter invoke CMake with independent bare -j arguments so the cap can be bypassed within the same lane.

## Conclusion

Route Radiance runtime/component/test and bump builds through existing cmake_build_args. Check effective argv under an explicit level and with no level before interpreting or repeating cold trials. See docs/reviews/astra-performance-2026-11-18/TOOLING.md.
