# Add standard console telemetry to CLI harness launches

## Description

Give every project-owned command-line harness a consistent launch/progress/completion trace showing session metadata, command identity, prompt/input summary, elapsed time, return code, and output summary.

## Steps

- Identify shared subprocess launch primitives and harness entry points.
- Implement a reusable, redacted console telemetry helper with quiet/default and verbose modes.
- Integrate it into command-line harnesses without changing captured artifact formats.
- Add unit tests and document the output contract in the experimental workflow.
