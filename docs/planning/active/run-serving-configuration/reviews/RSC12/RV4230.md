## Findings

Warm named start can recompute byte digests over engine and runtime artifacts for cache lookup and replay attestation. plan_cache.cpp materializes each full file before hashing. A separate replay gate hashes the complete gpus array, including transient used/free VRAM and current link data. The helper readiness loop rereads the entire role log per poll.

## Conclusion
