# Make atomic patch 1203 an executable, truthful multi-contract validation package

## Description

Patch 1203 already binds the three real contracts RD05/RD06/RD07 and has real backend-reference correctness producers in the shared campaign code. It still lacks an executable validation package because RD06/RD07 carry performance effects whose contract binding requires activation capability, while the 1203 patch currently has no confirmed real `BIGCHERRY_PATCH_TRACE` activation marker. Do not bypass `require_execution_package()` and do not invent a regex for a marker that source does not emit.

This item owns package/claim readiness. PA36 owns producer-code location; PA39 owns the final evidence-binding integration receipt.

## Steps

1. Re-read all three bound Experiment Contracts and derive required capabilities/check scopes from `bind_contract()` and the current plural `ValidationPlan` semantics.
2. Decide activation truthfully:
   - preferred: add a minimal `BIGCHERRY_PATCH_TRACE`-gated production-path marker in 1203's source transform that proves the atomic patch's relevant dispatch path executed, with zero behavior when tracing is off; or
   - if no truthful marker can represent the claim, revise the affected contract claim/policy through the Experiment Contract owner rather than fabricating activation evidence.
3. Author `patches/1203_rd050607_rdna4_wmma_fa_q6k_mmq/validation.toml` only after required capabilities have real producers. On a >1-contract plan, explicitly scope checks with `contracts=[...]`; unscoped checks do not satisfy plural contract-derived requirements.
4. Correctness: one atomic control/subject pair, built once as fat `gfx1100;gfx1201;gfx1030`, then run per real device. RD05/RD06 consume their gfx1201 result; RD07 requires all three architectures. Never rebuild per architecture and never claim causal isolation among co-tenanted RD05/06/07 changes.

6. Implement/migrate the shared 1203 producer under `patches/1203.../validation/` through PA36. Do not add new 1203-specific branches to `validation_campaign.py`.
7. Run package lint/plan resolution before real hardware execution.
