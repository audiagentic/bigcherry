# PA31 removes durable replay-equivalence regression coverage

## Findings

The PA31 implementation deletes the replay-equivalence harnesses and their tests as throwaway work. Those tests support the central PA20 safety claim: that the serving-only composition preserves replay behavior. Removing them means future changes can silently regress the boundary without an offline guard.

## Required follow-up

Retain a durable, hardware-free replay-equivalence test (and the minimal supporting oracle) in the repository. Hardware receipts may remain as evidence, but they should not be the only protection against later source-partition regressions.
