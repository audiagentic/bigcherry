# bigcherry patch-gates CLI (--intent validate/promote/build/rebase, --json)

## Description

Expose PA21's shared evaluator through a deterministic patch-gates CLI. This is a CLI consumer, not a second policy implementation.

## Steps

1. Add bigcherry patch-gates <patch-id> --intent {validate,promote,build,rebase} with --source for build/rebase where required.
2. Resolve the descriptor, full composition, pin, operation intent and evidence roots into PA21 GateContext.
3. Support --json with stable GateResult objects and human-readable output.
4. Exit 1 when any applicable required gate is FAIL or BLOCKED; NA is zero only when genuinely non-applicable. Resolution/schema errors exit 2. If report-only zero exit is needed, make it explicit.
5. Cross-check a real known-failing G7 patch against patch_admission.admit() and preserve native diagnostics.

## Detailed Solution & Technical Design

Wire cli/main.py and cli/patch.py to PA21 evaluate_patch_gates(). Do not call patch-verify-evidence as a substitute for the policy evaluator; it remains a read-only evidence verifier. Preserve operation-specific applicability and complete-composition resolution.
