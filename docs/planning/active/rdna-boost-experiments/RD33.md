# AMD-MMV-001: Decode matvec without Q8_1 activation quantization

## Description

Backend: HIP; source default RDNA3.5, validate gfx1100/gfx1201. Source: AMD PR Set 2 matvec item. Source status: Recheck before port. Prerequisites: none. Q8_0 relevance: Medium.

## Steps



## Detailed Solution & Technical Design

Hypothesis: For n=1 bandwidth-bound decode, skipping the q8_1 activation quantization pass and dequantizing weights directly can reduce overhead.

What/why: Activation quantization is pure overhead when matvec decode is bandwidth-dominated. AMD's set includes this plus a fused gate+up SwiGLU variant.

Where: single-column quantized matvec path.

## Code Samples & Guidance

Trigger: Qwen3.6 dense Q4/Q6/Q8 decode signatures; small/medium dense models (expose launch overhead).

Controls: prefill/small-batch n>1; large MoE expert matmuls; accuracy-sensitive quants.

Boundary: ncols_dst 1,2,3,4,8; model sizes 4B,9B,27B; context 0/64K/128K.
