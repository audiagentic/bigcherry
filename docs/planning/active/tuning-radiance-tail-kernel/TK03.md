# RX 6900 XT tail quad kernel: occupancy-specialised row batches and no padded-row work

## Description

The quad kernel's inner loop computes all RB=16 rows even when an expert has nr < 16 routed rows, wasting dot products, decode and reductions on lightly loaded experts. Both GPT reviews: select the row batch (4/8/16) by rows per expert rather than per request, keeping each valid row's K-fold order unchanged (bit-identical).

## Steps

1. Rows-per-expert histograms from the captures (cold, doc, decode).
2. Templated RB variants selected per expert occupancy (work descriptors per (expert, row tile)), valid rows only.
3. Bitwise sweep + timing on captures; extend captures with doc-text and multi-session prefill.
4. Production adoption with end-to-end A/B.
