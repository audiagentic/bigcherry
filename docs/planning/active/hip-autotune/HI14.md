# Multi-GPU validation and end-to-end graph capture verification

## Description

Add an offline, fail-closed validator for multi-GPU claim evidence. Validate device topology/count/ordinals/identities, explicit graph mode and capture observation, and complete per-device dispatch/signature/winner evidence. Keep HIP execution, tuning selection, and replay wire formats unchanged.

## Steps

- Single XTX (gfx1100) — full workload validation
- Single R9700 (gfx1201) — full workload validation
- Mixed XTX/R9700 — tensor split validation
- Multiple XTX devices — multi-device validation
- Actual PCIe topology and RCCL configuration used in production
- HIP graphs enabled — verify graph capture uses selected candidate
- pp256, pp1024, pp4096 benchmarks
- tg128/tg512 benchmarks
- MTP widths observed in inventory
- Long-context server workload
