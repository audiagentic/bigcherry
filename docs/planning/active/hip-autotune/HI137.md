Existing HI85 crash evidence is prerequisite truth and must not be repeated as the primary work. - Trace per-rank architecture selection and kernel loading/dispatch through RCCL's communicator, graph, and collective implementation; determine whether the incompatibility is a missing code object, incorrect per-rank selection, common-kernel assumption, or another source-level defect.
