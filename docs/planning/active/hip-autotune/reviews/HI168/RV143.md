# Tensor-split production logging lacks ordered physical device evidence

## Notes



## Findings

Two real stock27B dual-XTX startup cells rejected before measurement: default logging lacks init lines and Meta tensor backend omits physical membership. Raw KFD capture proves owned queues/VRAM on intended set but not backend ordinal order. Live fdinfo exposes memory/client/BDF only, no engine/cycle counters. Do not infer order from selectors, queue creation order, or identical-card assumptions. Reviewed bounded read-only process-memory fallback: exact ELF/source/ABI binding, actual initialized backend device ordinal/name/PCI fields, stable double-read, KFD physical-set corroboration, canonical ordered comparator unchanged. Raw prototype succeeds on stock default logging with clean shutdown, but prototype is not admission.

## Conclusion

Implement explicitly selected, hash/layout-bound raw backend-memory producer in existing attestation domain; reject unknown layout/binary, unstable/short reads, duplicate or unknown BDF, KFD-set disagreement. Preserve independent endpoint/work-equivalence/source/build admission. No injection, target function calls, ptrace stops, stock patch, or hot-path instrumentation.
