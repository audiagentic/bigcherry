# SQLite schema and Python loader for transform records — gap/attempt tables with observation join

## Description

Add two new tables to dispatch-db.sql for transform-attempt and transform-gap records, and update the Python loader to read transforms.jsonl alongside measurements.jsonl.

**transform_attempt table**: one row per transformation tried during tuning. Links to signature via signature_digest. Stores: transformation_id, source (PREDEFINED/DISCOVERED), original_native_family, transformed_signature_digest, transformed_winner_stable_name, original_us, transformed_us, improvement_pct.

**transform_gap table**: one row per signature where no transformation worked. Links to signature via signature_digest for join with observation table. Stores: pattern_description, native_family, transformations_tried_json (array of {id, rejection_reason}), calls, est_bytes (from observation merge).

**Python loader**: reads transforms.jsonl alongside measurements.jsonl, writes rows to both tables. Merges gap records with observations to populate calls/est_bytes.

## Steps

- Add transform_attempt table to dispatch-db.sql with FK to signature(signature_digest), candidate(candidate_id)
- Add transform_gap table with FK to signature(signature_digest) and JSON column for transformations_tried
- Add indexes: signature_digest on both tables, result/improvement_pct on attempt, pattern on gap
- Bump schema_meta.version to '2' and add transform_schema='1'
- Implement load_transforms() Python function that reads transforms.jsonl and inserts into SQLite
- Implement observation merge in transform_gap: look up calls/est_bytes from observation table by signature_digest
- Add INSERT OR IGNORE logic so re-running the loader doesn't create duplicates

-- --------------------------------------------------------------- transform_attempt
-- One row per (dispatch key, transformation) tried during tuning.

CREATE TABLE IF NOT EXISTS transform_attempt (
    attempt_id           INTEGER PRIMARY KEY,
    build_id             INTEGER NOT NULL REFERENCES build(build_id),
    hardware_id          INTEGER NOT NULL REFERENCES hardware(hardware_id),
    signature_digest     BLOB    NOT NULL REFERENCES signature(signature_digest),
    dispatch_digest      BLOB    NOT NULL,

    -- Which transformation was tried.
    transformation_id    INTEGER NOT NULL,
    transformation_name  TEXT    NOT NULL,       -- e.g. "transpose_weight_for_mmvf"
    source               TEXT    NOT NULL DEFAULT 'predefined'
        CHECK (source IN ('predefined', 'discovered')),

    -- Original context.
    original_native_family TEXT NOT NULL,         -- e.g. "blas"

    -- Result.
    result               TEXT    NOT NULL
        CHECK (result IN ('success', 'rejected')),
    rejection_reason     TEXT,                    -- null when success

    -- Transformed context (populated on success).
    transformed_sig_digest BLOB,                  -- null when rejected early
    transformed_winner_id  INTEGER REFERENCES candidate(candidate_id),

    -- Timing comparison.
    original_us          REAL,
    transformed_us       REAL,                    -- null if rejected before timing
    improvement_pct      REAL,                    -- positive = transform is faster

    -- Correctness metrics.
    nmse                 REAL,
    max_abs_error        REAL,

    attempted_at         TEXT    NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX IF NOT EXISTS transform_attempt_sig_idx
    ON transform_attempt(signature_digest);
CREATE INDEX IF NOT EXISTS transform_attempt_result_idx
    ON transform_attempt(result, improvement_pct DESC);

-- --------------------------------------------------------------- transform_gap
-- One row per signature where no transformation worked.
-- Primary input for agent analysis (HI32).

CREATE TABLE IF NOT EXISTS transform_gap (
    gap_id               INTEGER PRIMARY KEY,
    build_id             INTEGER NOT NULL REFERENCES build(build_id),
    hardware_id          INTEGER NOT NULL REFERENCES hardware(hardware_id),
    signature_digest     BLOB    NOT NULL REFERENCES signature(signature_digest),

    -- Pattern description for clustering.
    pattern_description  TEXT,                    -- e.g. "F32[1xK]xF32[KxN], N>8, falls to BLAS"
    native_family        TEXT    NOT NULL,         -- e.g. "blas"

    -- What was tried and why it failed.
    transformations_tried TEXT NOT NULL DEFAULT '[]',  -- JSON array of {id, name, reason}

    -- Observation data (merged from observation table at load time).
    calls                INTEGER NOT NULL DEFAULT 0,
    est_bytes            INTEGER NOT NULL DEFAULT 0,

    created_at           TEXT    NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX IF NOT EXISTS transform_gap_sig_idx
    ON transform_gap(signature_digest);
CREATE INDEX IF NOT EXISTS transform_gap_pattern_idx
    ON transform_gap(native_family, pattern_description);

## Schema Design

Two new tables: `transform_attempt` and `transform_gap`. Both reference `signature(signature_digest)` for join capability with observation data.

### transform_attempt Table

One row per (dispatch key, transformation) tried during tuning. A transformation can succeed (measured) or be rejected (can_apply failed, family_can_serve false, correctness check failed).

```sql
CREATE TABLE IF NOT EXISTS transform_attempt (
    attempt_id           INTEGER PRIMARY KEY,
    build_id             INTEGER NOT NULL REFERENCES build(build_id),
    hardware_id          INTEGER NOT NULL REFERENCES hardware(hardware_id),
    signature_digest     BLOB    NOT NULL REFERENCES signature(signature_digest),
    dispatch_digest      BLOB    NOT NULL,

    -- Which transformation was tried.
    transformation_id    INTEGER NOT NULL,
    transformation_name  TEXT    NOT NULL,       -- e.g. "transpose_weight_for_mmvf"
    source               TEXT    NOT NULL DEFAULT 'predefined',
        CHECK (source IN ('predefined', 'discovered')),

    -- Original context.
    original_native_family TEXT NOT NULL,         -- e.g. "blas"

    -- Result.
    result               TEXT    NOT NULL,       -- 'success' | 'rejected'
        CHECK (result IN ('success', 'rejected')),
    rejection_reason     TEXT,                    -- null when success

    -- Transformed context (populated on success).
    transformed_sig_digest BLOB,                  -- null when rejected before transform applied
    transformed_winner_id  INTEGER REFERENCES candidate(candidate_id),

    -- Timing comparison.
    original_us          REAL,                    -- native path median
    transformed_us       REAL,                    -- transformed path median (null if rejected)
    improvement_pct      REAL,                    -- positive = transform is faster

    -- Correctness metrics.
    nmse                 REAL,
    max_abs_error        REAL,

    attempted_at         TEXT    NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX IF NOT EXISTS transform_attempt_sig_idx
    ON transform_attempt(signature_digest);
CREATE INDEX IF NOT EXISTS transform_attempt_result_idx
    ON transform_attempt(result, improvement_pct DESC);
```

## Agent Query Patterns

**Prioritize gaps by impact:**
```sql
SELECT g.pattern_description, COUNT(*) as gap_count,
       SUM(o.calls) as total_calls, MAX(o.est_bytes) as max_bytes
FROM transform_gap g
JOIN observation o ON g.signature_digest = o.signature_digest
GROUP BY g.pattern_description
ORDER BY total_calls DESC;
```

**Find gaps where a specific transform was rejected:**
```sql
SELECT g.signature_digest, g.pattern_description, o.calls
FROM transform_gap g, json_each(g.transformations_tried) t
JOIN observation o ON g.signature_digest = o.signature_digest
WHERE t.value->>'id' = '1'  -- transpose_weight_for_mmvf
ORDER BY o.calls DESC;
```

**Successful transforms and their impact:**
```sql
SELECT a.transformation_name, COUNT(*) as attempt_count,
       AVG(a.improvement_pct) as avg_improvement,
       SUM(o.calls) as total_calls_affected
FROM transform_attempt a
JOIN observation o ON a.signature_digest = o.signature_digest
WHERE a.result = 'success'
GROUP BY a.transformation_name
ORDER BY total_calls_affected DESC;
```

## Python Loader

The loader reads both `measurements.jsonl` and `transforms.jsonl` from the same prefix:

```python
def load_dispatch_artifacts(db_path: str, prefix: str):
    """
    Load measurements.jsonl and transforms.jsonl into SQLite.
    prefix = GGML_HIP_DISPATCH_DB value (e.g. "/tmp/dispatch")
    """
    conn = sqlite3.connect(db_path)

    # Load header to get build/hardware info.
    header = load_jsonl_header(prefix + ".measurements.jsonl")
    build_id = ensure_build(conn, header['source_revision'],
                           header['manifest_hash'])

    # Load measurements (existing logic).
    load_measurements(conn, prefix + ".measurements.jsonl", build_id)

    # Load transform records.
    load_transforms(conn, prefix + ".transforms.jsonl", build_id)

    conn.commit()

def load_transforms(conn, path, build_id):
    """Load transform-attempt and transform-gap records."""
    for line in open(path):
        rec = json.loads(line)
        if rec['kind'] == 'transform-attempt':
            insert_transform_attempt(conn, rec, build_id)
        elif rec['kind'] == 'transform-gap':
            insert_transform_gap(conn, rec, build_id)
        # Skip header lines.

def insert_transform_attempt(conn, rec, build_id):
    sig_digest = hex_to_blob(rec['original_sig'])
    hw_digest = hex_to_blob(rec.get('hardware', ''))
    dispatch_digest = hex_to_blob(rec.get('dispatch', ''))

    # Resolve signature_id from signature table.
    sig_id = conn.execute(
        "SELECT signature_id FROM signature WHERE signature_digest = ?",
        (sig_digest,)).fetchone()
    sig_id = sig_id[0] if sig_id else None

    hw_id = resolve_hardware_id(conn, hw_digest)

    conn.execute("""
        INSERT OR IGNORE INTO transform_attempt (
            build_id, hardware_id, signature_digest, dispatch_digest,
            transformation_id, transformation_name, source,
            original_native_family, result, rejection_reason,
            transformed_sig_digest, transformed_winner_id,
            original_us, transformed_us, improvement_pct,
            nmse, max_abs_error
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
    """, (
        build_id, hw_id, sig_digest, dispatch_digest,
        rec['transformation_id'], rec['transformation_name'],
        rec['source'], rec['original_native_family'],
        rec['result'], rec.get('rejection_reason'),
        hex_to_blob(rec.get('transformed_sig', '')) or None,
        resolve_candidate_id(conn, rec.get('transformed_winner') or None),
        rec.get('original_us'), rec.get('transformed_us'),
        rec.get('improvement_pct'),
        rec.get('nmse'), rec.get('max_abs_error'),
    ))

def insert_transform_gap(conn, rec, build_id):
    sig_digest = hex_to_blob(rec['sig'])

    # Merge calls/est_bytes from observation if available.
    obs = conn.execute(
        "SELECT calls, est_bytes FROM observation WHERE signature_digest = ?",
        (sig_digest,)).fetchone()
    calls = obs[0] if obs else rec.get('calls', 0)
    est_bytes = obs[1] if obs else rec.get('est_bytes', 0)

    conn.execute("""
        INSERT OR IGNORE INTO transform_gap (
            build_id, hardware_id, signature_digest,
            pattern_description, native_family,
            transformations_tried, calls, est_bytes
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?)
    """, (
        build_id,
        resolve_hardware_id(conn, hex_to_blob(rec.get('hardware', ''))),
        sig_digest,
        rec.get('pattern'),
        rec.get('native_family', ''),
        json.dumps(rec.get('transformations_tried', [])),
        calls, est_bytes,
    ))
```
