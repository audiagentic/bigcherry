# bigcherry report command for tuning analysis

## Description

A `bigcherry report` command that reads tuning results (SQLite or JSONL) and produces formatted analysis reports.

Subcommands:
- `bigcherry report signatures` — per-signature detail tables (generated/eligible/measured counts, all candidates with status, median_us, MAD, p95_us, workspace, nmse)
- `bigcherry report summary` — improvement distribution (>10%, >5%, >1%), family comparison (% winners by family), rejection reason breakdown
- `bigcherry report families` — cross-family comparison for a specific dispatch digest (all measured candidates side-by-side)
- `bigcherry report hot` — top-N signatures by call count (requires observation table from record mode)

Output formats: human-readable table to stdout, or --json for machine consumption.

## Steps

- Create new `tools/bigcherry/report.py` module with CLI subparser
- Implement `report signatures` — read measurements.jsonl or SQLite, format per-signature tables with all candidate metrics
- Implement `report summary` — aggregate statistics: improvement distribution histogram, family winner counts, rejection breakdown
- Implement `report families` — for a given dispatch digest, show all measured candidates sorted by median_us with correctness data
- Implement `report hot` — join observation.calls with measurement results (requires SQLite with both record and tuning data)
- Add output format options: --json, --csv
- Support both JSONL input (--measurements FILE) and SQLite input (--database FILE)
- Write unit tests with small fixtures
