# HI121 close-out step 4: C++-authoritative canonical signature digest verification (RV84 P0-4)

CORE MECHANISM SOUND -- adversarial negotiation converged (2026-08-27, 3 rounds, req_63a2308dd7cc439c/req_38b1c5cfab66469e). Not a rubber-stamp: round 1 found a real, serious gap the initial real-hardware match had NOT proven -- digest equality alone doesn't prove the supplied canonical is what the hash was computed from, since signature_to_test_file_line() only reads ne0/ne1/ned/types and never nb0/nb1/nbd/prec/flags, always reconstructing natural contiguous strides regardless of what those fields claimed. A canonical poisoned in an ignored field would make the mapper reconstruct an identical real dispatch and observe the SAME digest -- exactly the poisoned-first-canonical attack this item exists to close.

Fixed (commit fbcf510): observed_test_backend_ops_signature_hex() now also returns the real observed canonical (hip-autotune-record.cpp already writes it alongside every observation's digest); observed_signature_digest_hex() requires it to exactly match the supplied canonical before trusting the digest. Second fix (commit 92640af): inventory.py's signature_cache short-circuit was independently bypassing the repeat-sighting disagreement check for same-load (not just cross-load) different-canonical-same-digest cases -- fixed via signature_seen_canonical tracking.

Closing round confirmation traced the actual C++ source structure to justify soundness (not just trust the report): ggml_hip_signature_digest() and ggml_hip_record_observation() both invoke ggml_hip_signature_json(sig, true) -- the SAME serializer, SAME arguments -- so no field can be hashed without also being recorded, or vice versa. This is why whole-dict normalized-JSON equality (not a field whitelist) is the correct comparison -- explicitly validated as the right design, since a whitelist would recreate exactly the future-field-omission vulnerability class this fix eliminates. Final GPT position, verbatim: 'I now consider HI125's core canonical-to-digest authority claim sound... I see no remaining concrete hole... I would not manufacture one.'
