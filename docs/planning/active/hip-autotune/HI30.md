# Tuner integration — try routing transformations when native selection yields a single-family result

## Description

Integrate routing transformations into the tuning flow. When the tuner encounters a signature where native selection picks a family but no eligible candidates exist (or only BLAS is eligible), try registered routing transformations to produce alternative launch contexts that other families can serve.

The integration point is in ggml_hip_tuner_resolve() — after the candidate set is gathered and screened, if the result shows generated==eligible==1 (only BLAS) or eligible==0, attempt transformations.

Each transformation produces a new launch context. The tuner measures both paths with complete-path timing: original (BLAS) vs transformed (whatever family the transform targets). If the transformed path wins by replacement_threshold_pct, install it as the winner with the transformation attached.

## Steps

- In ggml_hip_tuner_resolve(), after screening phase: check if eligible candidates are only BLAS (single family, count==1) or none exist
- If single-family result and not fused: iterate registered transforms
- For each transform: call can_apply(), then apply() to get transformed sig + lc
- Check family_can_serve on the target family for transformed sig
- Build candidate set from transformed sig (screening loop)
- Time original (BLAS) path using native_m->median_us (already measured)
- Time transformed path with complete-path timing (batch iteration included)
- compare_outputs(transformed, native_reference) — reject if nmse too high
- If transformed wins by replacement_threshold_pct: install as binding with transform_id
- Record transform-attempt (success/rejected) via HI29's API
- If no transform worked: record transform-gap with all rejection reasons

## Detailed Solution & Technical Design

## Integration Point

Transforms are tried **after** the normal candidate screening phase in `ggml_hip_tuner_resolve()`. The trigger condition:
1. The screening phase completed, AND
2. Eligible candidates exist but all belong to the same family (typically BLAS), OR
3. No eligible candidates exist at all.

Transforms are NOT tried when:
- The signature is fused (same rule as cross-family tuning — graph-level question)
- Multiple non-BLAS families already compete (tuner can pick the best natively)
- GGML_HIP_ROUTING_TRANSFORM is OFF

## Flow

```
ggml_hip_tuner_resolve()
  │
  ├── [existing] Gather candidates, screen by can_execute
  │     └── result.eligible measurements
  │
  ├── [new] Check: eligible == 1 (only BLAS) or eligible == 0?
  │     └── YES → try transforms
  │           │
  │           ├── For each transform in registry:
  │           │   ├── can_apply()? NO → skip, record rejection
  │           │   ├── apply() → transformed_sig + transformed_lc
  │           │   ├── family_can_serve(target_family, transformed_sig)? NO → skip
  │           │   ├── Re-run screening on transformed_sig → transformed_eligible
  │           │   │
  │           │   ├── transformed_eligible == 0? → record rejected attempt
  │           │   └── YES → measure both paths
  │           │         ├── Time original (BLAS) path → orig_us
  │           │         ├── Time best transformed path → trans_us
  │           │         ├── compare_outputs(transformed, native_reference)
  │           │         ├── record_transform_attempt(success/failed)
  │           │         └── If trans_us < orig_us by threshold:
  │           │             └── Install transformed winner + transform_id
  │           │
  │           └── No transform worked? → record_transform_gap()
  │
  ├── [existing] Winner selection, install binding
  │
  └── Return winner (original or transformed)
```

## Measuring the Transformed Path

The tuner already knows how to measure a candidate given a launch context. For transforms:

1. **Build an alternative candidate set** from the transformed signature: iterate registry, check `can_execute` on the transformed sig. This is the same screening loop as the existing code.
2. **Time the complete path**: for batch transforms, time the full batch iteration (not one batch). The dispatch layer will run the batch loop; we time exactly what it runs.
3. **Correctness check**: compare_outputs against the native reference output. This is critical — a transformation that produces different results must be rejected.

## Complete-Path Timing

For BATCH_FOR_MMVF, the complete-path timing must include:
- All batch iterations (num_batches kernel launches)
- Any pointer manipulation overhead
- Synchronization between batches (if any)

The `time_candidate` function already times the complete path of one candidate. For batch transforms, we need a wrapper that iterates:
```c
for (int batch = 0; batch < num_batches; ++batch) {
    // adjust src1 pointer and dst pointer for this batch slice
    time_candidate(candidate, lc_batch, ...);
}
```

This measures the actual dispatch-time cost.

## Binding with Transform

When a transformed path wins, the binding stored in `g_bindings` must carry:
- The original candidate (for the transformed sig)
- The transform_id
- The inverse_ctx data (for dispatch writeback)

The existing `Binding` struct needs extension. See HI31 for details.

## Guard Against Re-tuning

The result cache (`g_results`) is keyed on `dispatch_digest`. A transformed path produces a different signature, hence a different digest. But the **original** dispatch key still maps to the transformed winner — so we install the result under the **original** dispatch_digest. This prevents re-tuning: if the same original signature appears again, the cache returns the transformed winner immediately.

## Error Handling

- If the transformed path's can_execute fails at measurement time → record rejected attempt, try next transform
- If compare_outputs fails (nmse too high) → reject this transform, try next
- If no transform works → keep native binding, record gap

## Code Samples & Guidance

// hip-autotune-tuner.cu — inserted after screening phase, before scratch allocation:
#ifdef GGML_HIP_ROUTING_TRANSFORM
// --- routing transform attempt (standards 11.3) -----------------------
//
// Trigger: eligible candidates are only BLAS, or none exist.
// Try registered transforms to produce alternative launch contexts.
{
    const bool single_family = [&]() {
        if (screening.empty()) return false;
        const int fam = screening[0]->candidate->family;
        for (auto * m : screening)
            if (m->candidate->family != fam) return false;
        return true;
    }();

    if (!fused && single_family && screening.size() <= 1) {
        const int transform_count = ggml_hip_transform_count();
        std::vector<AttemptResult> tried_results; // for gap record

        for (int t = 0; t < transform_count; ++t) {
            const ggml_hip_routing_transformation * xform =
                ggml_hip_transform_find((ggml_hip_transform_id)(t + 1));
            if (!xform || !xform->can_apply(sig)) {
                tried_results.push_back({xform ? xform->id : 0,
                                         xform ? "can_apply failed" : "not found"});
                continue;
            }

            ggml_hip_dispatch_signature_v1 trans_sig = {};
            ggml_hip_launch_context trans_lc;
            void * inverse_ctx = nullptr;

            if (xform->apply(sig, &trans_sig, &trans_lc, &inverse_ctx) != 0) {
                tried_results.push_back({xform->id, "apply failed"});
                continue;
            }

            // Check that the target family can serve.
            const int target_family = (xform->id == GGML_HIP_TRANSFORM_TRANSPOSE_WEIGHT_FOR_MMVF)
                ? GGML_HIP_FAMILY_MMVF
                : GGML_HIP_FAMILY_MMVF;
            if (!ggml_hip_family_can_serve(target_family, trans_sig)) {
                tried_results.push_back({xform->id, "family_can_serve false"});
                continue;
            }

            // Build candidate set from transformed sig.
            std::vector<Measurement> trans_measurements;
            for (size_t i = 0; i < ggml_hip_registry_size(); ++i) {
                const auto * c = ggml_hip_registry_at(i);
                Measurement m;
                m.candidate = c;
                if (c->can_execute(c, trans_sig, hw)) {
                    m.workspace_bytes = c->workspace(c, trans_sig);
                    // Only consider target family candidates.
                    if (c->family == target_family) {
                        // Eligible — measure it.
                    }
                }
                trans_measurements.push_back(m);
            }

            // Find the best eligible candidate in the target family.
            Measurement * best_trans = nullptr;
            for (auto & m : trans_measurements) {
                if (m.candidate && m.candidate->family == target_family &&
                    m.candidate->can_execute(m.candidate, trans_sig, hw)) {
                    if (!best_trans || m.workspace_bytes < best_trans->workspace_bytes)
                        best_trans = &m;
                }
            }

            if (!best_trans) {
                tried_results.push_back({xform->id, "no eligible candidate in target family"});
                continue;
            }

            // --- measure both paths ------------------------------------
            // Time original (BLAS) path — already measured as native_m.
            const double orig_us = native_m->median_us;

            // Time transformed path with complete-path timing.
            ggml_tensor trans_dst = *lc_in.dst;
            trans_dst.data = candidate_buf.get();
            std::vector<double> gpu, host;

            if (xform->id == GGML_HIP_TRANSFORM_BATCH_FOR_MMVF) {
                // Batch iteration: time the full loop.
                auto * bctx = reinterpret_cast<batch_inverse_ctx *>(inverse_ctx);
                for (int batch = 0; batch < bctx->num_batches; ++batch) {
                    // Adjust pointers for this batch slice.
                    // ... (pointer arithmetic based on bctx)
                    if (!time_candidate(best_trans->candidate, trans_lc,
                                        config.warmup_launches, config.screen_samples,
                                        config.launches_per_sample, gpu, host)) {
                        tried_results.push_back({xform->id, "launch failed"});
                        goto next_transform;
                    }
                }
            } else {
                // Single launch.
                if (!time_candidate(best_trans->candidate, trans_lc,
                                    config.warmup_launches, config.screen_samples,
                                    config.launches_per_sample, gpu, host)) {
                    tried_results.push_back({xform->id, "launch failed"});
                    goto next_transform;
                }
            }

            const double trans_us = median_of(gpu);

            // Correctness: compare against native reference.
            CUDA_CHECK(hipMemcpyAsync(candidate_host.data(), candidate_buf.get(),
                                       dst_bytes, hipMemcpyDeviceToHost, lc.stream));
            CUDA_CHECK(hipStreamSynchronize(lc.stream));

            double nmse = 0.0, max_abs = 0.0;
            if (!compare_outputs(reference_host, candidate_host, nmse, max_abs) ||
                nmse > config.max_nmse || max_abs > config.max_abs_error) {
                tried_results.push_back({xform->id, fmt::format("nmse={:.6g}", nmse)});
                goto next_transform;
            }

            // --- transform succeeded — compare timings -------------------
            const double improvement = 100.0 * (orig_us - trans_us) / orig_us;

            ggml_hip_record_transform_attempt(
                result.signature_digest, xform, true,
                nullptr, &trans_sig, best_trans->candidate,
                orig_us, trans_us, nmse, max_abs);

            if (improvement >= config.replacement_threshold_pct) {
                // Install transformed winner.
                binding.candidate = best_trans->candidate;
                binding.variant   = best_trans->candidate->variant;
                binding.from_cache = true;
                // TODO: store transform_id in binding (see HI31)
            }

            goto done_transforms; // success — no need to try more

        next_transform:
            tried_results.push_back({xform->id, "handled"});
        } // for each transform

        // No transform worked — record gap.
        if (binding.candidate == native.candidate) {
            ggml_hip_record_transform_gap(
                result.signature_digest, result.hardware_digest,
                nullptr, // pattern — caller fills or omit
                (int)native.candidate->family,
                0,       // calls — not known in tune mode
                (int64_t)sig.ne0[0] * sig.ned[1] * sizeof(float), // est_bytes
                tried_results);
        }
    } // single_family check
}
done_transforms:
#endif // GGML_HIP_ROUTING_TRANSFORM

## Standards

- Transform attempt must use complete-path timing — include overhead of the transformation itself (not just kernel time)
- Transformed path must be validated against native reference output before being considered as winner
- If fused, do not try transformations (same rule as cross-family tuning — graph-level question)
- Transform attempt is zero-cost when GGML_HIP_ROUTING_TRANSFORM=OFF
