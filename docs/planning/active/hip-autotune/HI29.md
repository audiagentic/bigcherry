# Recording infrastructure — transform-attempt and transform-gap records for agent analysis

## Description

When the tuner evaluates routing transformations (HI28), record the results in JSONL alongside existing measurements, and also into SQLite for agent analysis. Two record kinds:

**transform-attempt**: a transformation was tried and either succeeded (measured) or failed (rejected). Records original sig, transformed sig, original native family, transformation applied, timing comparison, improvement_pct, and whether it was PREDEFINED or DISCOVERED.

**transform-gap**: no transformation could serve the signature. Records the original sig, pattern description, which transformations were tried and why each was rejected, call count, est_bytes. This is the input for agent-driven analysis — an agent can find patterns across many gaps and propose new transformations.

**Data flow**:
1. Runtime writes `transforms.jsonl` (crash-safe, line-by-line) — same GGML_HIP_DISPATCH_DB prefix as measurements
2. Offline Python loader reads both `measurements.jsonl` and `transforms.jsonl`, writes all to SQLite
3. Agent queries SQLite directly — can join gaps with observations for prioritization

**Schema** (new tables in dispatch-db.sql):
- `transform_attempt`: signature_digest, transformed_signature_digest, transformation_id, source (PREDEFINED/DISCOVERED), original_native_family, transformed_winner, original_us, transformed_us, improvement_pct
- `transform_gap`: signature_digest, pattern_description, native_family, transformations_tried_json, calls, est_bytes

- Define TransformAttempt struct in hip-autotune-tuner.cu with all fields from JSONL schema plus json() method

## Detailed Solution & Technical Design

## Data Flow

```
tuner_resolve() 
  │
  ├── transform attempt succeeds → record_transform_attempt(kind=success)
  │
  ├── transform attempt fails   → record_transform_attempt(kind=rejected)
  │
  └── all transforms tried, none worked → record_transform_gap()
```

## Record Schema (JSONL)

**transform-attempt** — one line per (signature, transformation) tried:
```json
{"kind":"transform-attempt",
 "original_sig":"<hex_digest>",
 "transformation_id":1,
 "transformation_name":"transpose_weight_for_mmvf",
 "source":"predefined",
 "original_native_family":"blas",
 "result":"success|rejected",
 "transformation_reason":"mmvf eligible after swap" | "ne01!=1",
 "transformed_sig":"<hex_digest>",
 "transformed_winner":"mmvf:f32:w1:bs128:accf32:v1",
 "original_us":78.4,
 "transformed_us":3.8,
 "improvement_pct":95.2,
 "nmse":0.0,
 "max_abs_error":0.0}
```

**transform-gap** — one line per signature where no transform worked:
```json
{"kind":"transform-gap",
 "sig":"<hex_digest>",
 "hardware":"<hex_digest>",
 "pattern":"F32[1xK]xF32[KxN], N>MMVF_MAX_BATCH_SIZE, falls to BLAS",
 "native_family":"blas",
 "calls":42,
 "est_bytes":8388608,
 "transformations_tried":[
   {"id":1,"name":"transpose_weight_for_mmvf","reason":"ne01!=1"},
   {"id":2,"name":"batch_for_mmvf","reason":"k%2!=0"}
 ]}
```

## Flush Integration

In `ggml_hip_tuner_flush()`, after the existing measurements.jsonl flush, flush transform records to a separate file:
```c
#ifdef GGML_HIP_ROUTING_TRANSFORM
{ // transform records
    std::string transforms_path = path + ".transforms.jsonl";
    FILE * f = fopen(transforms_path.c_str(), "w");
    if (f) {
        fprintf(f, "{\"kind\":\"header\",...}\n"); // same header pattern
        for (auto & r : g_transform_attempts)
            fprintf(f, "%s\n", r.json().c_str());
        for (auto & r : g_transform_gaps)
            fprintf(f, "%s\n", r.json().c_str());
        fclose(f);
    }
}
#endif
```

## Calls/est_bytes Source

The gap record includes `calls` and `est_bytes`. These come from the observation table — which is populated in record mode **before** tuning. In tune mode, the observation is not collected by default, but the tuner has access to the signature and can compute est_bytes from tensor sizes:
```c
int64_t est_bytes = (int64_t)sig.ned[0] * sig.ned[1] * sizeof(float);
```
Calls are 0 in tune mode (we don't count them there). The offline Python loader merges with observations when both exist.

## Code Samples & Guidance

// hip-autotune-tuner.cu — inside GGML_HIP_ROUTING_TRANSFORM block, before ggml_hip_tuner_flush:

#ifdef GGML_HIP_ROUTING_TRANSFORM
// ---------------------------------------------------------------- transform records
struct TransformAttempt {
    ggml_hip_digest original_sig;
    ggml_hip_transform_id transform_id;
    std::string transform_name;
    std::string source;            // "predefined" | "discovered"
    std::string original_native_family;
    std::string result;            // "success" | "rejected"
    std::string rejection_reason;
    ggml_hip_digest transformed_sig;
    std::string transformed_winner;
    double original_us = 0.0;
    double transformed_us = 0.0;
    double improvement_pct = 0.0;
    double nmse = 0.0;
    double max_abs_error = 0.0;

    std::string json() const {
        return fmt::format(
            "{{\"kind\":\"transform-attempt\"," 
            "\"original_sig\":\"{}\"," 
            "\"transformation_id\":{},"
            "\"transformation_name\":\"{}\"," 
            "\"source\":\"{}\"," 
            "\"original_native_family\":\"{}\"," 
            "\"result\":\"{}\"," 
            "\"rejection_reason\":\"{}\"," 
            "\"transformed_sig\":\"{}\"," 
            "\"transformed_winner\":\"{}\"," 
            "\"original_us\":{:.3f},"
            "\"transformed_us\":{:.3f},"
            "\"improvement_pct\":{:.3f},"
            "\"nmse\":{:.6g},"
            "\"max_abs_error\":{:.6g}" 
            "}}",
            ggml_hip_digest_hex(original_sig),
            (int)transform_id,
            transform_name, source,
            original_native_family, result,
            rejection_reason,
            transformed_sig ? ggml_hip_digest_hex(transformed_sig) : "",
            transformed_winner,
            original_us, transformed_us,
            improvement_pct, nmse, max_abs_error);
    }
};

struct TransformGap {
    ggml_hip_digest sig;
    ggml_hip_digest hw;
    std::string pattern;
    int native_family = 0;
    int calls = 0;
    int64_t est_bytes = 0;
    std::vector<AttemptResult> tried; // {transform_id, rejection_reason}

    std::string json() const {
        std::string j = fmt::format(
            "{{\"kind\":\"transform-gap\"," 
            "\"sig\":\"{}\"," 
            "\"hardware\":\"{}\"," 
            "\"pattern\":\"{}\"," 
            "\"native_family\":{},"
            "\"calls\":{},"
            "\"est_bytes\":{}," 
            "\"transformations_tried\":[",
            ggml_hip_digest_hex(sig),
            ggml_hip_digest_hex(hw),
            pattern, native_family,
            calls, est_bytes);
        for (int i = 0; i < (int)tried.size(); ++i) {
            if (i) j += ",";
            j += fmt::format(
                "{{\"id\":{},\"reason\":\"{}\"}}",
                tried[i].transform_id, tried[i].rejection_reason);
        }
        j += "]}";
        return j;
    }
};

static std::vector<TransformAttempt> g_transform_attempts;
static std::vector<TransformGap> g_transform_gaps;
static std::mutex g_transform_mutex;

void ggml_hip_record_transform_attempt(
        const ggml_hip_digest & orig_sig,
        const ggml_hip_routing_transformation * xform,
        bool success,
        const char * reason,
        const ggml_hip_dispatch_signature_v1 * trans_sig,
        const ggml_hip_candidate_descriptor * winner,
        double orig_us, double trans_us,
        double nmse, double max_abs) {
    std::lock_guard<std::mutex> lock(g_transform_mutex);
    TransformAttempt r;
    r.original_sig = orig_sig;
    r.transform_id = xform->id;
    r.transform_name = xform->name;
    r.source = xform->source == GGML_HIP_SOURCE_PREDEFINED ? "predefined" : "discovered";
    r.result = success ? "success" : "rejected";
    r.rejection_reason = reason ? reason : "";
    if (trans_sig) r.transformed_sig = ggml_hip_signature_digest(*trans_sig);
    if (winner) r.transformed_winner = winner->stable_name;
    r.original_us = orig_us;
    r.transformed_us = trans_us;
    r.improvement_pct = orig_us > 0 ? 100.0 * (orig_us - trans_us) / orig_us : 0.0;
    r.nmse = nmse;
    r.max_abs_error = max_abs;
    g_transform_attempts.push_back(r);
}

void ggml_hip_record_transform_gap(
        const ggml_hip_digest & sig_dig,
        const ggml_hip_digest & hw_dig,
        const char * pattern,
        int native_family,
        int calls,
        int64_t est_bytes,
        const std::vector<AttemptResult> & tried) {
    std::lock_guard<std::mutex> lock(g_transform_mutex);
    TransformGap r;
    r.sig = sig_dig;
    r.hw = hw_dig;
    r.pattern = pattern ? pattern : "";
    r.native_family = native_family;
    r.calls = calls;
    r.est_bytes = est_bytes;
    r.tried = tried;
    g_transform_gaps.push_back(r);
}
#endif // GGML_HIP_ROUTING_TRANSFORM
