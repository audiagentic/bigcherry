# Ordered per-step speculative acceptance trace equality (aggregate counts are structurally insufficient)

## Description

The behavioural gate compares generated token IDs plus AGGREGATE (draft_n, draft_n_accepted) scalars. behavioral_gate.py's own docstring already flags this as a known limitation; dev-gpt-agent (req_bdb8d2b1) confirms it must be closed and that the need is STRUCTURAL -- it does not require waiting for an equal-aggregate/different-order failure to be observed first.

These two trajectories are indistinguishable to the current gate:

  [(4,4), (4,0), (4,4)]
  [(4,2), (4,2), (4,4)]

Both aggregate to 12 drafted / 8 accepted, while executing different work schedules. llama-server's n_accepted_per_pos does not solve it either: it is a cumulative histogram by draft position, so [1,3] and [3,1] still collide.

This matters now rather than theoretically. A promoted cache measured acceptance 0.94734 -> 0.86391, bit-identical across 16 cells, and that difference alone accounted for what looked like a 9% tg512 regression. Any comparison whose arms differ in acceptance is comparing different amounts of work, not different speeds.

## Steps

1. Record, in order, per speculative step: draft_n and accepted_n, plus an acceptance bitmap or accepted indices if acceptance is not guaranteed to be a prefix.
2. Emit ordered_trace_digest alongside total_drafted, total_accepted and step count in the normal artifact; retain the FULL ordered trace only on mismatch, so the common case stays small.
3. Make the gate's equality condition: generated output equal AND ordered acceptance trace equal. Anything else is BEHAVIOR CHANGED and requires the throughput adjudication step.
4. This needs llama-server-side instrumentation exposing an ordered per-step trace, which the response API does not expose today -- that is the actual work, and behavioral_gate.py's docstring already names it as required follow-up.

## Effort & Risk

The gate is a promotion blocker, so a false positive here stops legitimate winners.
