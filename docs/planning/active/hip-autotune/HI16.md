## Notes

### Forced-native parity is now load-bearing

HI06-HI08 thread the forced variant value as an explicit parameter rather than
a hidden override. That keeps production free of tuning cost, but it means the
forced path is separate code from the native path, so these tests stop being a
formality:

```text
forced J           == native J_best           -> bitwise-identical output
forced block_size  == native block_size_best  -> bitwise-identical output
forced nwarps      == native nwarps_best      -> bitwise-identical output
```

Each must be checked per type and per shape class, because the forced value
travels through a different chain of defaulted parameters for each. A mistake
in any forwarding site shows up here and nowhere else -- the code compiles and
runs either way.


### Review update

**Cross-language digest agreement is a required test.** Keys are computed in
C++ at runtime and in Python by the offline tools. A divergence does not fail
loudly -- every replay lookup simply misses and falls back to native, so the
system looks like it works while doing nothing. `hip-autotune-blake2b.cpp`
therefore has known-answer vectors pinned against Python `hashlib.blake2b`
(7 vectors passing, including the RFC 7693 reference). Extend the same
treatment to canonical-JSON signature serialisation once refinements land.

**Patch-engine tests are part of this suite.** `tools/tests/test_patcher.py`
covers the failure modes that produce *silently wrong* output rather than an
error: greedy anchors landing an edit hundreds of lines away, anchors matching
inside comments or string literals, ambiguous anchors, and half-applied patch
sets. 10 tests, all passing. Two of the four cases were real bugs found this
way.

**The audit must survive its own patches.** Once HI06-HI09 land, the constructs
the audit inspects have moved. It now looks for each in its post-patch home
first and reports which state it found, so a re-run on a patched tree is not a
false failure. Extend as each forced-variant patch lands.

**`hip-autotune-inspect` belongs here** as well as in HI15 -- catalog/registry
agreement is most cheaply tested by the tool that reads both.
