# Remove legacy compat.recipe patch-selection path

## Description

config/recipes.toml carries two parallel recipe-selection mechanisms: v2 canonical [source.*] patch-sets (resolved by campaign/resolution.py:resolve_lane(), used by build --lane and campaign tooling) and legacy [compat.recipe.*] states/groups blocks (loaded by recipes.py:_load_v2_compat(), used by pull, patch-rebase-check, patch-doc, pin-bump, probe-release/validate-ref, and doctor). The two can genuinely disagree about what's 'in' a named recipe -- surfaced as a real bug where `patches --recipe bigcherry` reported a patch as selected that the real v2 patch-set.framework used by actual builds does not include. recipes.py's own docstring calls _load_v2_compat() a temporary bridge ('exists only so old pull/audit/build commands can continue operating while the campaign path migrates') that was never finished.

## Steps

Full plan with gpt-dev-agent review already drafted at C:\Users\mgs\.claude\plans\bright-rolling-snowglobe.md (not auto-loaded into this item's body -- transcribe key points below). Summary: (1) build one shared canonical selection helper ({source_name, source_ref, patch_set_id, patch_ids}) tested standalone first; (2) migrate patch-rebase-check first (strongest contract test, has selector-freshness checks); (3) migrate remaining consumers one at a time -- patches/apply/generate/status/check, patch-doc, pull (needs ref only, read cfg.sources[source].ref directly, don't route through full lane resolution), pin-bump (same source name must flow through all 3 phases), probe-release/validate-ref, doctor (resolve build/platform directly from v2 config if actually needed); (4) decide compat-only recipe names (dev/release/core/upstream/workstation/b10257) case by case -- add a real v2 source only if worth keeping long-term, else drop with recorded disposition, ask user before dropping; (5) decide --groups/--states override flag fate (separate ad-hoc mode vs deprecate, never silently reinterpret against ResolvedPatchSet); (6) final repo-wide grep for Recipe/RecipeError/_load_v2_compat/compat.recipe/recipes.get, then one final commit deleting compat blocks + loader + types together -- no thin compatibility shim.
