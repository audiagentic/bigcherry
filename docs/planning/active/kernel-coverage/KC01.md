# First-class non-GEMM kernel-family lifecycle coverage

## Description

Define and implement the lifecycle representation for kernel families not covered by the five generic tuner families, starting with FLASH_ATTN and GDN. Cover discovery, eligibility, workspace, launch, measurement, correctness, identity, replay, promotion, demotion, and closure without duplicating existing RD04-RD08 or RD50-RD53 experiments.

## Steps

1. Inventory existing experiment-contract support and reuse it. 2. Define family-specific identity and eligibility fields for Flash Attention and GDN. 3. Bind existing RD experiments to those identities. 4. Add negative/blocked/disposition outcomes. 5. Validate exact replay and promotion/demotion behavior.

## Detailed Solution & Technical Design

Extend the existing experiment-contract and patch lifecycle architecture only where required; do not add parallel family registries. FLASH_ATTN must cover native and provider FMHA candidates. GDN must preserve hardware gating and blocked-on-hardware evidence.
