# GPT deep-dive: 1326 async-input staging lifetime and prefill cost

## Notes



## Findings

1. Lifetime: the thread_local unordered_map<input_cpy, vector<uint8_t>> staging + ggml_backend_tensor_set_async is safe on HIP by API contract (pageable source => hipMemcpyAsync copies synchronously; HSA_ENABLE_SDMA only changes the engine). Not contractually safe on CUDA (cudaMemcpyAsync with a pageable source may still be in flight at return). Vulkan pageable path stages again and synchronizes, defeating the optimisation. Meta fans the same host pointer to every child with no lifetime retention; meta hardcodes caps.events=false and caps.host_buffer=false.
2. Prefill -0.6% likely from: extra memcpy per eligible input into pageable memory (HIP then copies synchronously, no real async H2D), unordered_map hash per input, thread_local lifetime retained across graph rebuilds, 4 MiB cap too broad (small control/index/mask inputs eligible).
3. Recommended design: scheduler-owned pinned ring (3 slots per input x backend, flat array, host buft from ggml_backend_dev_host_buffer_type) with a completion event per slot (event_record after set_async, event_synchronize before slot reuse), freed in ggml_backend_sched_free. Meta needs a composite event over child events and caps.events/host_buffer derived from the children. Tune the size cap from an input-size histogram.
4. Tests: synthetic H2D overwrite stress (sizes 1..4 MiB, ring depth 1/2/3, forced copy backlog; removing the event wait must corrupt), SDMA=0/1/unset on gfx1030/1100/1201, meta axis 0/1/2 + MIRRORED with a delayed child, llama path ub 1/2/4/8 logits/greedy vs 1326 off, perf A/B at 16K/64K with staging-copy and ring-wait counters.

## Conclusion

Current 1326 stays opt-in (sched-async profile); not default-on. It is HIP-correct today, so the flashnext/hip profiles may keep it. Default-on for HIP only after the pinned event-ring + meta composite event rework lands in 1326 itself, the stress tests are clean, and the 16K prefill regression is gone or gated by size class. No CUDA/Vulkan enablement without backend-specific lifetime tests.
