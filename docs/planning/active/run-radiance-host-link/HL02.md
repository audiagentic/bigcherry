# Contention A/B: GPU pull vs CPU BAR push for the consumer card while XTX 0 reads

## Description

All RAD50 push gains so far are on idle links (R9700 combine 1.25x serial at 768 rows, ~1.0x at 1-16). Under XTX 0 read contention the pull halves while the push does not, so the system-level gain may be much larger. RAD50's S6 contention gate is still open.

## Steps

1. Add a background-load arm to rad50-tester (or reuse RAD40 host-pull.hip): steady host reads on XTX 0.
2. Measure the R9700 (and XTX 1) consuming 256-2048-row planes by GPU pull vs DMA-BUF CPU push, with and without the background load; record the other cards' throughput too.
3. Report transfer makespan and the background card's rate for each arm.
