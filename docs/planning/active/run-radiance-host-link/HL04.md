# Prefill-only CPU-combine push into R9700 VRAM: is the combine on the flashnext-4gpu critical path?

## Description

RAD50 proved the DMA-BUF push into R9700 VRAM bit-exact (1 row 0.97x, 16 1.07x, 64 1.11x, 256 1.18x, 768 1.25x serial, idle CPU). Only prefill-sized steps can gain, and only if the CPU combine sits on the critical path. Decide before any moe-remote change.

## Steps

1. Per-layer prefill trace on flashnext-4gpu: combine start/end, engine add wait, helper result done (RAD40 trace contract).
2. If the engine waits on the combine: opt-in push for steps >= ~256 rows, pull below; per-chunk ready flags so the GPU consumes while the CPU writes.
3. A/B prefill (doc + long fill) and decode separately; KL unchanged.
