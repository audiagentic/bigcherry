# CPU-push the helpers' activation copies instead of each helper pulling them (prefill activation round)

## Description

RAD40: a 5.4 MB activation round to each helper at once finishes XTX 0 662 us, XTX 1 853 us (651 uncontended), tail 1,601; CPU-pushing XTX 0's copy instead cut the heads' makespan 853 -> 683 us (-20%). In flashnext-4gpu prefill every MoE layer step does this round, so it is a per-layer gain, a different application of the RAD50 push than the result combine.

## Steps

1. Model: per-layer prefill critical path with the measured activation round (trace contract from RAD40's review).
2. Lab: CPU push of activations into helper VRAM (DMA-BUF) with per-chunk ready generations, vs today's helper pull; bit-exact payload.
3. Only if the lab clears RAD40's stop/go (>= 15% transfer makespan or >= 0.3 ms off a layer step): opt-in moe-remote transport behind a manifest setting, A/B on prefill and decode separately.
