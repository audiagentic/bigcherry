# QSA attention is O(n_kv) in compute; f16 draft KV wins at depth

## Notes

Scripts: tools/lab/flash-next/draft-ab.sh, long-ctx-profile.sh decode mode with DEPTH.

## Findings

1. Attention cost per decoded token, summed over GPUs, 10K vs ~80K cached (rocprof decode windows, flashnext-draft-ab-1/decode-10k vs flashnext-long-ctx-decode-3): target verify flash_attn_tile 0.44 -> 3.36 ms/tok (7.6x), draft flash_attn_ext_vec 0.18 -> 1.41 ms/tok (7.7x) for 8x context. build_attn_qsa passes the full K/V cache to build_attn_mha and expresses the selection only as a -inf mask over n_kv, and the HIP FA tile/vec kernels do not skip fully masked KV tiles, so QSA attention reads the whole cache. 2. Draft KV q8_0 vs f16 ABBA (target KV q8_0, MTP3): 10K 50.4/49.9 vs 49.0/48.8 ms/step (-2.5%); 80K 66.0/65.7 vs 60.4/60.0 ms/step (-8.8%), complete separation.

## Conclusion

Highest-value RNX02 patch: true sparse QSA - gather the selected K/V rows (sel_idx, n_sel ~ top_k + tail) into a compact buffer and run attention over n_sel instead of masking n_kv; expected to bring 80K attention to ~10K cost (~4 ms/token summed, ~6-9% of 80K decode, more at 160K-192K, plus long-prompt prefill). Alternative: teach the FA tile/vec kernels to skip fully masked KV tiles. Deployment now: -ctkd f16 -ctvd f16.
