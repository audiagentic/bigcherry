## Capability matrix

For each source kernel, identify use of gfx12-only WMMA/intrinsics, wave-size assumptions, LDS footprint, BF16/FP8/MXFP4 hardware dependence, UVA/system-memory assumptions, and host/P2P assumptions. Classify:
- `common`: same algorithm can compile/run everywhere with tuning only.
- `gfx12-native/gfx11-portable`: dataflow reusable but math primitive/tiling changes.
- `gfx12-only-format`: format depends on hardware support; do not emulate unless E2E model wins justify it.
- `reject`: no matching llama.cpp hot path or already fully covered.
