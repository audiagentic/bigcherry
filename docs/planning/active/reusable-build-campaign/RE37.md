# Environment-action campaign inputs for non-patch experiments (driver/ICD/ASPM/hipBLASLt)

## Description

Represent non-patch experiment environment inputs as typed, hashed, immutable campaign inputs. Extend existing allow-listed build-environment/toolchain capture without mixing system mutations into patch identity.

## Steps

Define EnvironmentAction/EnvironmentSnapshot kinds for driver/ICD, OS/kernel, ROCm/Vulkan/toolchain, env overrides, ASPM policy, and offline tuning files; capture normalized values and file hashes; publish an immutable artifact; include its digest in experiment/build/evidence identity; enforce allow-list and secret rejection; expose applied/observed/failed action status.

## Detailed Solution & Technical Design

Reuse campaign BuildPlan.environment, toolchain.capture_environment(), experiment_bundle.safe_environment(), ArtifactStore, and provenance records. Add a typed environment-input digest composed with—not substituted for—source/patch/build identity. For actions that mutate the host, record pre/post observations and require explicit lane opt-in; do not silently mutate production hosts.

## Code Samples & Guidance

```python
@dataclass(frozen=True)
class EnvironmentInput:
    kind: Literal["observation", "action", "artifact"]
    name: str
    values: tuple[tuple[str, str], ...] = ()
    files: tuple[tuple[str, str], ...] = () # path, sha256
    digest: str = ""
    reversible: bool = False
```
Normalize observations (driver/ICD/tool versions), hash file inputs (hipBLASLt/CK solutions), and keep mutating actions separate with pre/post snapshots. Compose `environment_input_digest` into experiment evidence/build identity; do not insert system fields into patch_set_id.

## Validation

Add deterministic normalization/hash tests, secret rejection, file tamper detection, read-only observation proof, and action pre/post failure recording. Reuse `toolchain.capture_environment`, `experiment_bundle.safe_environment`, ArtifactStore, and provenance rather than creating another ambient-env capture system.

## Effort & Risk

M/high operational risk; distinguish observation from mutation and never hash the entire ambient environment.

## Standards

Align with HIP's allow-listed environment identity and immutable ArtifactStore; retain source/build/runtime identity separation.
