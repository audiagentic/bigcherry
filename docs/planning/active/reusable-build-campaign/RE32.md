# Vulkan candidate eligibility ABI: can_execute() cannot evaluate real Vulkan capability yet

## Description

Resolve the provisional Vulkan eligibility ABI before candidate/replay implementation. Current vk-autotune-types.h intentionally keeps capabilities outside ggml_vk_hardware_key_v1, but can_execute and replay lookup cannot currently inspect them.

## Steps

Define a typed immutable VulkanCapabilitySnapshot containing normalized API/driver identity, device features/extensions/limits/subgroups, and shader/toolchain digest. Give it a canonical serialization/digest. Pass the snapshot or digest-bound capability reference to candidate preflight and replay lookup. Keep compact hardware identity separate from capabilities, but require both digests for compatibility. Add unsupported-extension/limit tests.

## Detailed Solution & Technical Design

Follow HIP's separation of signature, hardware identity, candidate descriptor, and observation, but do not copy its structs. Candidate can_execute must receive the resolved capability snapshot at build/runtime selection. Replay lookup must reject mismatched capability and shader digests before returning a binding. The snapshot is immutable for one process/lane and should be captured once, not reconstructed from ad hoc JSON at each call.

## Code Samples & Guidance

```cpp
struct ggml_vk_capability_snapshot_v1 {
    uint32_t version;
    uint32_t vendor_id, device_id;
    uint32_t api_version, driver_version;
    uint64_t feature_bits;
    uint32_t max_workgroup[3];
    uint32_t subgroup_size;
    std::string device_uuid;
    std::string extensions_digest;
    std::string shader_toolchain_digest;
};
struct ggml_vk_execution_context_v1 {
    ggml_vk_hardware_key_v1 hardware;
    ggml_vk_capability_snapshot_v1 capabilities;
};
using ggml_vk_can_execute_fn = bool (*)(const ggml_vk_candidate_descriptor &, const ggml_vk_execution_context_v1 &);
```
If ABI exposure of strings is undesirable, use fixed canonical byte digests plus an internal owning snapshot. The replay key must include hardware digest + capability digest + shader digest; can_execute receives the owning resolved context.
