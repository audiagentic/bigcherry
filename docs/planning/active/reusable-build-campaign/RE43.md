# Add bigcherry patch list / patch explain / patch graph CLI subcommands

## Description

External patch-management review, Section 16: a small patch-management CLI reduces maintenance burden more than an elaborate folder structure. `bigcherry patch list` should show ID/class(kind)/state/plan/backend per patch with filters (--class experiment, --backend vulkan, --state untested, --plan RD44). `bigcherry patch explain <id>` should show source, plans, contracts, requires, conflicts, which recipes select it, current state, content hash, and files touched. `bigcherry patch graph` should show dependency/conflict topology as a textual graph (sufficient initially, no need for a rendered image).
