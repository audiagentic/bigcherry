## Detailed Solution & Technical Design

GPT-auto-agent full implementation plan (2026-08-17), second priority after RE25. Depends on RE25's ArtifactDescriptor/ProvenanceV2/typed rehydration landing first. PipelineService remains the invariant gate, not a second orchestrator -- one stage at a time, public functions.

New files: lifecycle_specs.py (WorkloadExecutionSpec + per-stage spec dataclasses), lifecycle_workers.py, lifecycle_stages.py (public execute_record_stage/execute_inventory_stage/execute_tune_stage/execute_promotion_stage/execute_replay_export_stage/execute_replay_validation_stage, each returning a typed *StageResult), runtime_execution.py (workload_argv/sanitized_environment/verify_model/run_workload), replay_validation.py (moved out of ab_benchmark.py), ggml_types.py (parse_type_values/read_type_values, replacing replay_cache's ggml.h reparse dependency).

Key changes: PipelineService gets ArtifactRequirement(kind,expected,require_promotable,count) + run_contract() for per-kind multi-input contracts (tune needs both a runtime-bundle AND an inventory, different kinds). make_generate_worker() additionally emits a ggml-type-map artifact so replay export doesn't need to reparse ggml.h from a source tree at export time. CampaignLaneExecutionSpec gets allow_legacy_inputs: bool=False -- raw Path inputs rejected by default once ArtifactLocator/descriptor rehydration is the normal path; the compat probe (release_validate.py) and re14_real_run.py explicitly opt in.

Test file: test_re10_lifecycle_stages.py -- real git materialize, REAL executable fake compiler+fake llama-bench script (not mocked subprocess) that inspects GGML_HIP_DISPATCH_DB env var and writes real record/measurements JSONL, so the full record->inventory->tune->promote->replay chain runs for real end to end including real tune_promotion.promote() and real replay_cache building, only the actual compile/GPU work faked. Proves: descriptor rehydration works across a fresh ArtifactStore instance; raw inventory path taints imported-legacy and promotion rejects it; wrong-source production inventory fails before tune runs.
