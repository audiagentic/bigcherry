# RCCL Phase 2: topology-aware qualification/tuning/replay for the RCCL-viable device subset

## Description

HI138 (closed 2026-08-29, Outcome B) definitively established that RCCL AllReduce is viable and crash-free for any tensor-split topology on this box EXCLUDING physical device 3 (the RX 6900XT, permanently limited to META by a real, non-fixable hardware constraint -- its chipset-routed PCIe root port has no AtomicOps completion capability). Confirmed empirically (20/20 reps): {0,1}, {0,2}, {1,2}, {0,1,2} all pass RCCL cleanly, including the real heterogeneous XTX+R9700 (gfx1100+gfx1201) pair. HI138's own closing notes explicitly recommend spinning this out: 'Recommend a fresh HI138 sub-scope or a new plan item for Phase 2 execution ... rather than continuing to grow this item's already-long history.' This item is that follow-up, created 2026-09-02 while reorganizing accumulated work from the compat.recipe-removal/HI135/HI138 investigation session.

Why this matters: HI18's own evidence shows RCCL is ~40x faster than META on the validated homogeneous pair. The same speed advantage should be available for the R9700-inclusive heterogeneous/3-GPU subset ({0,2}, {1,2}, {0,1,2}) once qualified -- this is real, uncaptured wall-clock-reduction opportunity for any workload that can avoid device 3.
