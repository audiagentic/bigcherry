# RX 6900 XT tail quad kernel: register-permute W4 decoder instead of the LDS table (bit-identical)

## Description

The gfx1030 tail's accurate rows kernel (lane_moe_rows_w4_quaddpp, moe_lane_gemm.h ~834) is 71% of the tail's GPU time on cold/varied prompts; the tail bounds flashnext-4gpu cold-prompt TTFT (11.4 s on 27k synthetic prompts, tail busy ~73%). It decodes W4NL nibbles through an LDS lookup table. The GEMV already decodes the same levels with register byte permutes (w4nl_to_h2x2), producing the exact same f16 bits in the same element order. Swap the decoder (both GPT reviews' first bit-identical idea).

## Steps

1. Replay form `quad_perm` (OPT bit 0) beside production (branch exp/rad49-tail-quad-perm, archived as git tag archive/exp-rad49-tail-quad-perm).
2. Replay the 40 captured tail requests (runs/rad49-tail-capture/cap/req-18-*.bin) in one --replay-sweep: zero mismatches vs production.
3. rocprofv3 timing, alternating forms, gate/up and down separately (runs/rad49-tail-quadperm).
4. If faster: make it the production decoder (no switch left behind), KL + cold/doc/long-fill A/B.

## Detailed Solution & Technical Design

GPT seed (gateway reviewer, 2026-11-10; full text runs/rad49-gpt-review/seed/):

Promote the tested register decoder, preserving the quad kernel's K128 loop, K64 folds, DPP reduction order, scaling operations, and final BF16 rounding.The experimental implementation at `wt-tail-quadperm/.../moe_lane_gemm.h` takes two sets of low nibbles and high nibbles and decodes each through `w4nl_to_h2x2`. Its returned packed half values replace the LDS LUT's four `uint32_t` words.The byte layout must remain:// Existing packed W4 input. h2v a01, a23, b01, b23; w4nl\_to\_h2x2(w & 0x0F0F0F0F, &a01, &a23); w4nl\_to\_h2x2((w \>\> 4) & 0x0F0F0F0F, &b01, &b23); uint4 decoded = make\_uint4( bitcast\_u32(a01), bitcast\_u32(a23), bitcast\_u32(b01), bitcast\_u32(b23));`bitcast_u32` is illustrative; production uses the existing `__builtin_bit_cast`.Remove the obsolete LUT storage and initialisation only after the new decoder is selected. Do not add a production switch for the old path. Preserve the current RAD46 small-request dispatch separately.
