# IQ8R CPU/GPU QKV mismatch is a BF16-folded scale precision regression

## Notes



## Findings

C06 host and mixed-AQL issued checkpoint tensors agree on all 36,864 INT8 input codes and 144 FP32 activation scales; XTX/R9700 intermediate results agree bitwise. However the reference GEMM in libref/ref_gemm.cpp:459-477 multiplies the IQ8R U8 group scale by BF16 row scale in FP32, while libr4d/r4d_fp8_layout.cpp:305-317 and libhalo/halo_fp8_layout.cpp:343-351 pre-round that product into BF16. An independent checkpoint-backed 198-value QKV projection sample matched CPU 198/198 with full FP32 folding, and matched GPU 198/198 with BF16 folding (the converse only 126/198). Changing the CPU to match GPU would hide numerical information loss and is forbidden as a 'fix'.

## Conclusion

Create one generic upstream Radiance owner RUM15 for FP32-preserving IQ8R GPU scale computation. LTX02 keeps model TP1 activation/quality parity; RUM15 owns generic kernel layout/GEMM change and its GPU regressions.
