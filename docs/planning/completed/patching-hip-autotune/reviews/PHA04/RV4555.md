# Reject invalid RCCL correctness counts before verification

## Notes



## Findings

RCCL JSON wrong counts passed through int(), which treats 0.8 as 0 and False as 0 and permits -1 and +1 to cancel across pass records. Five fake-child fixtures reproduced four false PASS cases before correction.

## Conclusion

Accept only non-negative decimal count strings or actual non-negative integers; reject booleans, fractions and signed values. Keep execution and hardware qualification gates pending, with no RCCL runtime or provider modification.
