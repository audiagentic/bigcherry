# TR09 Move build_parser/entrypoint into cli/main.py (CLI split complete)

## Description

Final TR09 slice: moved build_parser(), _add_selection_args, _legacy_main, _configure_output, cmd_repin, cmd_pin_status, and the ten thin _*_main forwarders (tune_journal/tune_promote/tune_null_fdr/experiment/ab_benchmark/campaign_build/resource_report/validate_release/rank_replay/candidate_binary_size) out of __main__.py into cli/main.py, which now owns argparse assembly and dispatch and imports every cmd_* handler directly from its owning cli/<domain>.py submodule (no dependency back on __main__). __main__.py re-exports build_parser/_legacy_main/cmd_repin/cmd_pin_status/_configure_output as module attributes (same pattern as the other extracted handlers) so existing tests resolving them via bigcherry.__main__ keep working unchanged.
