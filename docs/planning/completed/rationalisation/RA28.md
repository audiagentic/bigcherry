# Fix .gitignore shadowing tools/bigcherry/build/ and tuning/ domain packages

## Description

Discovered while committing the TR10 build-domain move: .gitignore's blanket build/ (line 2, for CMake output) and tuning/ (for tuning/replay data) patterns were also matching tools/bigcherry/build/ and tools/bigcherry/tuning/ by basename -- the TR01 domain-package skeletons themselves, including their __init__.py files from RA02, which were therefore NEVER tracked in git despite existing since that slice. This surfaced concretely once TR10 started moving real content (builds.py etc.) into build/. Fixed with explicit negations (!tools/bigcherry/build/, !tools/bigcherry/tuning/) right after each broad pattern; confirmed __pycache__ subdirectories within them remain correctly ignored.
