# Stage deliberate migration from generated libr3 to upstream libr3d

## Notes



## Findings

Upstream libr3d is a native gfx11 provider with shared ABI/operator schemas and its own implementations. Its row constraints and collective coverage do not match the complete BigCherry libr3 production path. RUM03's comparison build and KAB01 evidence remain useful until parity is established.

## Conclusion

Keep current component ownership and qualification. Put the native baseline, compute deltas, transport/mixed-rank qualification and final retirement in RCS15–18. No retirement before release assets, helper settings, code-object and selected-row parity gates pass. See docs/reviews/radiance-native-libr3d/INTEGRATION.md.
