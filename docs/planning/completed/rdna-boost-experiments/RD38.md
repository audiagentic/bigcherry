# AMD-GEMM-004: Large-M F16 shadow to tuned hipBLASLt crossover

## Description

Backend: HIP, gfx1100/gfx1201. Source: #57. Source status: Recheck before port. Prerequisites: PRBE29 (AMD-GEMM-002); RD37 (AMD-GEMM-003) optional. Q8_0 relevance: Very high.

## Detailed Solution & Technical Design

Hypothesis: Above an architecture/shape-specific physical M, tuned hipBLASLt on a persistent F16 shadow beats native quantized MMQ.

What/why: AMD's #57 uses hipBLAS for sufficiently large batches; BigCherry should derive the crossover from measurements, not inherit a fixed threshold.

Where: dense MUL_MAT dispatch between native Q MMQ and F16-shadow BLAS.

## Code Samples & Guidance

Trigger: Qwen3.6-27B Q8_0, every major dense-projection signature; Q4/Q6 secondary.

Controls: M<=128, decode, memory-constrained lane.

Boundary: M=64,128,192,256,384,512,768,1024,2048,4096; compare MMQ, hipBLASLt default, hipBLASLt tuned.
