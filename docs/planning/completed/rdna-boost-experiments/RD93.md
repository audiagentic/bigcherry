# Hardware-blocked patch retirement policy (PRBE16/RD22-class items)

## Description

If this list grows to ten such patches, that's dead weight being maintained indefinitely with no plan to ever resolve it.

## Steps

Track hardware_blocked_since / last_source_recheck / last_upstream_equivalence_check / next_review_date per hardware-deferred item. Add an automatic retire-or-recheck policy: if a patch stays hardware-blocked past some real threshold with no recheck, flag it for an explicit human decision (retire, or confirm still worth carrying) rather than letting it silently accumulate as permanent dead weight.
