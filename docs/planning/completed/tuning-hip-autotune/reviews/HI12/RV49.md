## Findings

GPT adjudication of the 7-finding review pass over hip-autotune-tuner.cu / dispatch / replay and Python tuning tooling. F1 (P0, real): native-relative acceptance (max_nmse 1e-6 vs native + max_abs 1e-2) does not compose into end-to-end correctness; verified the Python leak too - autotune_catalog.py:651 hardcodes tolerances {nmse:1e-6, max_abs:1e-2} from read_correctness_evidence() into production manifest evidence, so fixing only C++ would not close F1. Contract: CPU reference R is the canonical oracle; require E_N=NMSE(R,N) <= T (T = upstream gate, 5e-4 for the relevant MUL_MAT cases) AND E_C=NMSE(R,C) <= E_N + 0.5*(T-E_N); named/versioned correctness_headroom_fraction default 0.5 recorded in evidence; worst result across >=3 deterministic input seeds recorded; max_abs(C,R) <= max_abs(N,R) across the same trials (no new fixed absolute tolerance); rename the existing check to delta_nmse_vs_native as a screening invariant only. Mode consequence: until reference-grade correctness exists, tune mode = measure/select/record with actual workload dispatch REMAINING NATIVE (today it installs the resolved candidate into the real binding); replay executes only externally validated/promoted winners; promotion requires CPU-reference evidence keyed by source/manifest + architecture + signature + candidate; read_correctness_evidence() must stop treating tuner-native deltas as production proof. F2 (P0, real - worse than reported): canary retry overwrites native's AND twin's median/mad/p95/host/samples with retry-only stats but NOT their final_gpu_us arrays, so policy ranking mixes retry-only effective_us for the pair with original-block effective_us for other finalists while paired_sign_test still reads the original arrays - two measurement blocks inside one decision. Fix: measure complete finalist block; on canary fail run pair retry strictly as a stability probe; if probe fails -> UNRESOLVED retain native; if probe passes -> ONE fresh COMPLETE finalist block (every finalist) becomes the sole ranking dataset, its canary evaluated once with no further retry; discard the QC-failed original block for ranking (no pooling of any kind). Confirmation stage is independent and unaffected directly but can be affected in WHICH candidate gets confirmed. F6 (P1, real): g_tuner_poisoned + g_smi_runtime_disabled are process-global permanent; make poison keyed by HIP device + context generation; no time-based or success-based auto-clear; tuner must never call hipDeviceReset(); recovery only when the surrounding backend proves context/device execution-generation recreation (HI64 supplies that signal); make SMI-disable and cached host-sync-overhead device-local too. F3 (accept): g_bindings cache means the process-wide single-flight serializes new tuning work, not steady-state dispatch; production replay never online-measures by design. If a future adaptive serving mode is added it must be nonblocking (per-device ownership + try_lock + native fallback), never a request queued behind a long tune. F4 (P2): screening copies the full candidate output D2H for every eligible candidate (correction: determinism recheck does this only twice, for the selected winner); if profiling shows it material, implement an EXACT device-side reduction over the complete output (sum sq diff, sum ref sq, max abs diff, any nan/inf) copying only scalars - no strided subsampling, no deferred correctness; do only after F1 since F1 changes what the reference means. F5 (P2/P3): decompose ggml_hip_tuner_resolve when F1/F2/F6 touch it (correctness evaluation, final-round measurement, canary assessment, policy selection, determinism check, confirmation); make canary transition logic a CPU-testable function over FinalRoundBlock/CanaryOutcome so F2 is not pinned only by Python source-text contract tests; avoid one giant mutable RunState. F7 (accept): tuning is bounded evidence-producing mode (~several MB for ~1150 signatures per HI12 sizing); no cap/LRU now - eviction risks throwing away evidence ggml_hip_tuner_flush() needs; if adaptive online tuning ever lands, split compact winner/binding cache from durable/evictable full evidence.
