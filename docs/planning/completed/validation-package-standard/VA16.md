# VA09A: plural registry metadata (PatchDescriptor.experiment_contracts)

## Description

Per GPT round-10 review (req_16d7e7158cb14331). tools/bigcherry/patch/registry.py: PatchDescriptor.experiment_contracts: tuple[str,...] as the canonical field. patch.toml gains list key experiment-contracts=[...]; legacy singular experiment-contract still accepted, normalized to a one-element tuple; reject both keys present together, an explicit empty plural list, duplicate IDs, and unknown contract IDs; resolve/hash every bound contract during discovery, failing discovery if any is missing. Real fix: patches/1203_rd050607_rdna4_wmma_fa_q6k_mmq/patch.toml gains experiment-contracts = ["RD05-WMMA-FA-CORRECTNESS-BARRIERS", "RD06-RDNA4-WMMA-FA-CONFIG", "RD07-Q6K-MMQ-PREFILL-FOLD"] (currently has no contract binding at all despite plan-item=RD05/RD06/RD07). Add a temporary compatibility property `experiment_contract` returning the sole contract for 0/1-contract patches, raising PatchRegistryError for multi-contract patches (fail closed for any caller not yet updated for plural access, never silently picking one).
