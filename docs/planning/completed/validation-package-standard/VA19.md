# Exclude generated tooling residue from validation-digest identity

## Description

Real bug found during VA16's before/after digest investigation (GPT round-10, req_1c131ba025834afe): registry._validation_identity() hashed every file under a packaged patch's validation/**, so __pycache__/.ruff_cache/*.pyc tooling residue made validation identity depend on unrelated local tooling state rather than real authored content -- caused a real false-positive digest mismatch for RD08 during VA16's verification. Fixed with a centralized exclusion (_is_generated_tooling_residue()): directory names __pycache__, .ruff_cache, .pytest_cache, and file suffixes .pyc/.pyo are excluded from the file walk.
