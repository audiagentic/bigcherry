# ArtifactDescriptor persistence + kind-specific provenance contracts

## Description

RE08's remaining RV48-required work, split out because RE08's core verified defect (raw-path provenance laundering) is closed and doesn't need to wait for this broader design surface. Add ArtifactDescriptor -- a frozen, independently-serializable dataclass(artifact_id, kind, relative_path, content_hash, provenance: ProvenanceV2) -- that ArtifactStore can persist and rehydrate (RE11's cross-process resume needs exactly this: today CampaignRun.records is process memory only). Add kind-specific provenance contracts so provenance.validate() stops accepting all-five-namespaces-empty as sufficient for production artifact kinds.

## Steps

1. Design ArtifactDescriptor as a frozen dataclass, JSON-serializable (no Path objects -- relative_path as a string), with a stable artifact_id derivation.
2. Add ArtifactStore.persist_descriptor()/rehydrate_descriptor() (or equivalent) so a descriptor round-trips: persist, rehydrate, byte-verify against the store.
3. Define kind-specific provenance contracts: runtime-bundle requires source slice + source-plan/patch lineage + build plan + effective build + runtime-bundle identity; inventory requires producer source/build identity; promoted-winner/correctness artifact requires producer tune namespace; release report requires campaign/report identities.
4. Wire contract validation into provenance.validate() (or a new provenance.validate_for_kind()) so a document missing its kind's required fields is rejected, not silently accepted because the five namespaces merely exist as (possibly empty) dicts.
5. Migrate real producers (campaign_workers.py's generate/build/smoke workers, campaign_lane.py's materialize/input-resolution) to populate the now-required fields per kind.

## Detailed Solution & Technical Design

### RE25.3 — final slice: sticky taint propagation + descriptor-backed lane inputs (spec locked per RV50)

After RE25.3 lands and its tests pass, this item closes (state: completed). Nothing in RE25 remains open.

**3.1 One small cross-process input handle.** In artifacts.py:
`@dataclass(frozen=True) class ArtifactLocator: artifact_id: str` — nothing more. In campaign_lane.py: lane inputs accept `Path | ArtifactRef | ArtifactLocator`. No general artifact-query language, resolver service, or catalog.

**3.2 Normalise every lane input to a descriptor-backed ArtifactRef in _resolve_lane_inputs():**

- ArtifactLocator → `store.rehydrate(artifact_id, expected_kind=name)`; use the returned ref unchanged (kind already verified by rehydrate).
- ArtifactRef WITH artifact_id → rehydrate by ID and verify the returned kind + content_hash agree with the supplied ref (closes the RE25.2-review follow-on: a claimed nonempty artifact_id must be re-verified, not trusted). Use the rehydrated ref.
- ArtifactRef WITHOUT artifact_id → legacy/imported evidence only: never first-party production. Taint it imported-legacy; it cannot launder into production (test required).
- raw Path → read/hash bytes; build a typed ProvenanceV2 with project.provenance_class="imported-legacy" and NO invented source/build lineage — REMOVE the current unearned claim that stamps THIS lane's source_slice_id onto imported evidence (verified present in campaign_lane.py today); publish via `publish_bytes_ref()` so the input gets a real descriptor identity. Keep embedded-provenance sniffing where it exists: an embedded PRODUCTION doc is used, but the output class is still derived by taint from that doc, never elevated by the caller.

**3.3 Actually feed parents into derive() — no parents=() when real parents exist.** Fix sites (verified against code 9d55a9b):

- generate: campaign_execution.py `_run_generate`/`_stage_provenance` — parents = all lane-input refs consumed, via `ProvenanceV2.from_document(ref.provenance)`. Note generate currently bypasses derive() entirely and builds ProvenanceV2 directly with local_class — it must go through derive() so taint applies.
- build: campaign_workers.py run_build — parents = generated manifest/tree refs + direct lane needs (inventory/promoted-winners). The parent_artifact_ids + BuildProvenance.inputs half is already done in 9d55a9b; this adds the ProvenanceV2 parents so the class taints.
- smoke: campaign_workers.py run_smoke — parents = binary + runtime-bundle.
Required invariant (test): imported inventory → generated artifacts imported → build imported → runtime bundle imported → smoke imported → require_promotable rejects at every hop; while a descriptor-backed production inventory stays production end-to-end, and a development run stays development.

**3.4 Enforce kind contracts at PUBLICATION.** Add `validate_for_kind(provenance.document(), kind=kind)` inside ArtifactStore._publish_ref() (the common publish_*_ref path). NOT in persist_descriptor(): RE25.1 tamper tests call persist_descriptor() directly with deliberately corrupt descriptors and must keep failing at load/rehydrate time, not persist time. Non-production classes pass because validate_for_kind skips the production-field contract for them.

**3.5 Tests (all required):** raw Path input gets a real artifact_id; its descriptor rehydrates in a fresh ArtifactStore; raw input is imported-legacy; build/runtime-bundle derived from it remain imported-legacy; require_promotable(runtime_bundle) rejects; production descriptor input stays production end-to-end; development source stays development; wrong-source production descriptor rejects before generate runs; descriptor kind mismatch rejects; ID-less ArtifactRef cannot launder into production; production descriptor missing a kind-required field fails AT PUBLICATION. Re-run the RE24 adversarial matrix as regression.

**EXPLICIT NON-GOALS for RE25 (stop after 3.5):** no second descriptor schema, no descriptor database, no artifact GC, no artifact graph queries, no provenance service, no generic runtime-bundle framework refactor, and no kind contracts for hypothetical future output kinds — a new contract is added only when a real producer introduces the kind.

## Validation

An ArtifactDescriptor round-trips through the store (persist, rehydrate, byte-verify). Each kind-specific contract rejects a document missing its required fields. Existing empty-namespace test fixtures either get real fields or are explicitly grandfathered as non-production kinds -- audit however deliberately calls out empty namespaces as 'a useful early-stage shape but not complete production provenance', so production kinds must fail without real fields.

## Effort & Risk

M -- touches provenance.py's validation contract, a shared primitive multiple producers depend on; must not silently break the real hardware-proven RE16-RE22 provenance flow while tightening it.
