# Add bigcherry patch list / patch explain / patch graph CLI subcommands

## Description

Extend the existing patches CLI rather than creating a second command family. cmd_patches already supports CatalogSnapshot plus kind/backend/origin filters; add state/plan/subsystem/hardware filters and explain/graph views.

## Steps

Confirm command spelling/backward compatibility; add list filters; implement patch explain with module/catalog metadata, plans, recipes, state, hashes, files touched, requires/conflicts, and upstream status; implement textual graph with cycle/conflict highlighting; use one CatalogSnapshot per invocation; return nonzero on catalog inconsistency.

## Detailed Solution & Technical Design

Reuse patch_catalog.CatalogSnapshot, patchset.PatchModule, upstream_landed(), recipe config, and module REQUIRES/CONFLICTS. Do not infer relationships from filenames or duplicate metadata. Keep output deterministic and machine-readable mode optional; make explain/graph read-only.

## Code Samples & Guidance

Suggested parser shape, extending existing `patches` command:
```text
bigcherry patches list --kind framework --state validated --plan RD44
bigcherry patches explain 1217_rd44_graph_opt_default_rdna35
bigcherry patches graph --roots 1217_rd44_graph_opt_default_rdna35
```
Keep `bigcherry patches` as the backward-compatible list alias. Build one CatalogSnapshot; join `snapshot.modules`, catalog entries, `cfg.patch_sets`/`cfg.experiments`, and module `requires/conflicts`. Emit stable text first; add `--json` only if consumers need machine parsing.

## Files

tools/bigcherry/__main__.py; tools/bigcherry/patch_catalog.py; tools/bigcherry/patchset.py; tools/bigcherry/recipes.py; tools/tests/test_patch_cli.py

## Validation

Golden tests should cover current output compatibility, filters, unknown IDs, a module with requirements/conflicts, upstream landed/unknown status, catalog inconsistency, and deterministic ordering. Explain must show content hash and exact source path; graph must mark cycles/conflicts.

## Effort & Risk

M/medium; joining recipes/plans requires careful handling of legacy compatibility aliases.
