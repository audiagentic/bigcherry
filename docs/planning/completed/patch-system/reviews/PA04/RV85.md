# Reference documentation placement audit and package-only patch correction

## Notes

User-directed audit of docs/reference found invalid index links, patch-specific evidence/test artifacts stored at reference root, and package-only patch direction that contradicts PA04's retained-flat-patch acceptance criterion.

## Findings

The complete local-link audit initially found 15 broken links in five maintained/reference files: two incorrect archive links in architecture/DESIGN_DECISIONS.md, five source links in architecture/FAMILY_MODEL.md, seven archived source links in archive/FAMILY_MODEL.md, and the TOOl_DISPOSITION planning link in tooling/TOOLING.md. All were corrected and the re-run resolved every local Markdown link. The reference root also contains: (1) 1005 patch-specific C++ test fixture/source/results, (2) RD21/RD50 shared eligibility helper plus two patch-specific activation records, (3) cross-patch validation evidence consumed by bigcherry.patch.evidence and patch_admission, and (4) the HI35/HI36 campaign corpus including a pipeline script, caches, SQLite DB, JSONL logs, and >1 GiB of CSVs. The first two are patch-owned and belong in packages once their flat patches migrate. The third is a single runtime authority and cannot simply move without resolver/data-migration work. The campaign corpus is evidence/artifact material, not reference prose, and is currently intentionally transitional under TOOL_DISPOSITION pending a caller/ownership audit. PA04 and patch reference docs currently state that flat patches remain first-class, conflicting with the requested package-only policy.

## Conclusion

Incorporated: corrected all local reference links and shared-tree-unsafe reset instructions; created PA18 to migrate to package-only patch ownership without creating a second loader/evidence framework; created reference-documentation work to resolve the remaining campaign/artifact placement. RV85 findings are therefore triaged and ready to close.
