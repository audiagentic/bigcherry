## Description

HI109 (real dense Qwen3.8-27B/Q8_0 production campaign, 2026-08-24 Brutus): after HI111 fixed quantized-type support in `signature_to_test_file_line()`, 105/113 real hypotheses got correctness evidence. The remaining 7 (of 8) skips were all real MTP-traffic signatures with a batched src1 outer dimension -- `src1=(2,1)`, `(3,1)`, `(4,1)` -- rejected by the same non-batched/contiguous restriction `signature_to_op_filter()` and `signature_to_test_file_line()` both enforce (outer dims must be exactly `(1,1)`). These are almost certainly MTP's multi-draft-token verification batches (spec-draft-n-max=5 in production), not synthetic/rare shapes -- real production traffic routinely produces them.
