# Compile-only CI check for both HIP autotune build configurations (tune-mode and replay-only)

## Description

The current offline pytest suite only does source-text pattern matching, never compilation. This session found a production-breaking compile bug (hip-autotune-dispatch.cu referencing a transform-only type outside its GGML_HIP_ROUTING_TRANSFORM guard) that broke every GGML_HIP_DISPATCH_REPLAY=ON build -- the actual production configuration -- and it had apparently never been compiled before. Add a cheap compile-only check (no GPU needed, just cmake configure + build of ggml-hip/llama-server) for BOTH GGML_HIP_AUTOTUNE=ON (tune-mode) and GGML_HIP_DISPATCH_REPLAY=ON (replay-only, autotune off) configurations, run before landing any change touching hip-autotune-*.cu/.cuh/.h.
