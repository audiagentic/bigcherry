# HI121 close-out step 2: source+target manifest/descriptor attestation (RV84 P0-2, P1-1, P1-2)

## Description

RV84 P0-2/P1-1/P1-2, confirmed real by dev-gpt-agent's independent investigation (2026-08-26). P0-2: project_measurements() loads --source-manifest and immediately trusts its candidate descriptors without first proving recomputed source manifest hash == source manifest.manifest_hash == DB build.manifest_hash, source_revision match, build_descriptor hash match, and producer_capabilities match against DB/header attestation. P1-1: descriptor mismatch is only rejected when BOTH stored DB descriptor and incoming descriptor are non-null -- an HI121-projectable build should require all three (DB build_descriptor_hash, header descriptor, source manifest recomputed descriptor) to exist and be exactly equal; old descriptor-less builds should be capability-unknown/not-projectable, not silently passed. P1-2: _verify_and_persist_hip_capabilities() compares header descriptor hash against manifest['build_descriptor']['descriptor_hash'] and independently recomputes manifest_hash(), but manifest_hash() deliberately EXCLUDES build_descriptor -- so the descriptor object itself is never independently recomputed and cross-checked; catalog.build_descriptor(manifest) should be recomputed and exact-compared against the embedded descriptor.

## Steps

1. Add _load_source_manifest(...) to replay_projection.py with the same fail-closed rigor _load_target_capabilities() already has -- bound to source_build_id and the current measurements header (recomputed hash/revision/descriptor/capabilities all cross-checked against DB and header before any candidate list is read).
2. Apply the same strictness to the target manifest path (P1-1/P1-2 affect both sides per dev-gpt-agent's investigation, not just source): require DB build_descriptor_hash, header descriptor, and independently-recomputed manifest descriptor to all exist and match exactly for any HI121-projectable build.
3. Recompute catalog.build_descriptor() from each manifest (minus its own embedded descriptor authority) and exact-compare against the embedded descriptor hash, on both source and target sides.
