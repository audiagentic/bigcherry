# Make release-record and index publication crash-safe

## Description

Close the offline release persistence gap. ReleaseRecord.save currently publishes release JSON and rebuilds the index without interruption/recovery guarantees or consistency validation.

## Steps

- Audit stage monotonicity, broken transitions, reload round-trips, and duplicate/unknown records.
- Publish release JSON and index through atomic temporary-file replacement.
- Add consistency validation that every index entry matches its source record and stale entries fail closed.
- Test interrupted publication and recovery from temporary files.
