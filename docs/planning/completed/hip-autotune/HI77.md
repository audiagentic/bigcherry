# Detect/enforce overlay-to-vendor source sync (src/ggml vs vendor/llama.cpp drift)

## Description

src/ggml/... is the tracked canonical overlay source; vendor/llama.cpp/... (gitignored) is what actually compiles. Nothing enforces or flags that they're in sync -- a fix can be made, committed, and tested against the overlay while the compiled tree still runs stale code. Hit this directly this session: fixed a bug, rebuilt, got identical broken output, because only the overlay copy had been edited. Add a check (in `bigcherry audit` or a dedicated script) that diffs src/ggml/... overlay files against their vendor/llama.cpp/... counterparts and fails loudly on drift, or automate the sync as a build prerequisite.
