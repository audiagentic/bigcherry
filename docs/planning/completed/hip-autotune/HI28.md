# Predefined routing transformations — transpose_weight_for_mmvf and batch_for_mmvf

## Description

Implement the first two routing transformations that map a signature falling to BLAS (or other single-family) into an alternative launch context served by a different family. These are the patterns discovered from PR #26171 and its generalization.

**transpose_weight_for_mmvf**: F32[1×K] × F32[K×N], N > MMVF_MAX_BATCH_SIZE → swap operands, reshape dst to [N×1], call mmvf with ne11=1. Mathematically equivalent because (AᵀB)ᵀ = BᵀA for single-column A.

**batch_for_mmvf**: F32[M×K] × F32[K×N], N > MMVF_MAX_BATCH_SIZE → split into ceil(N/8) batches of ≤8, call mmvf per batch, write back to dst. Equivalent because matmul distributes over column partition.

## Steps

- Implement TRANSPOSE_WEIGHT_FOR_MMVF:
  - can_apply(): ids==nullptr && ne01==1 && ne11>MMVF_MAX_BATCH_SIZE && src0==F32 && contiguous
  - transform(): create launch_context with swapped src0/src1, reshaped dst_vec, record inverse writeback mapping (identity — mmvf writes to same memory, just different stride interpretation)
  - equivalence_verified: true (transpose of single-column weight is mathematically guaranteed)
- Implement BATCH_FOR_MMVF:
  - can_apply(): is_float && k%2==0 && ne11>MMVF_MAX_BATCH_SIZE
  - transform(): create per-batch launch contexts with sliced src1 and dst pointers
  - equivalence_verified: true (column partition preserves matmul semantics)
- Register both in the transform registry array
- Validate: both transformations produce launch contexts that satisfy MMVF family's family_can_serve constraints

// hip-autotune-transform.cu
#ifdef GGML_HIP_ROUTING_TRANSFORM
#include "hip-autotune-transform.cuh"
#include "mmvf.cuh"  // for MMVF_MAX_BATCH_SIZE

// ---------------------------------------------------------------- TRANSPOSE_WEIGHT_FOR_MMVF
static bool transpose_weight_can_apply(
    const ggml_hip_dispatch_signature_v1 & sig) {
    if (sig.flags & GGML_HIP_SIG_HAS_IDS) return false;
    if (sig.src0_type != GGML_TYPE_F32) return false;
    if (sig.ne0[1] != 1) return false;       // M == 1
    if (sig.src1_type != GGML_TYPE_F32) return false;
    const int64_t width = sig.ned[1];
    return width > MMVF_MAX_BATCH_SIZE;       // only useful when mmvf can't serve
}

static int transpose_weight_apply(
    const ggml_hip_dispatch_signature_v1 & orig_sig,
    ggml_hip_dispatch_signature_v1 * out_sig,
    ggml_hip_launch_context * out_lc,
    void ** out_inverse_ctx) {
    memcpy(out_sig, &orig_sig, sizeof(*out_sig));

    // Swap src0↔src1 dims and types.
    for (int i = 0; i < 4; ++i) {
        int64_t ne_tmp = out_sig->ne0[i];
        out_sig->ne0[i] = out_sig->ne1[i];
        out_sig->ne1[i] = ne_tmp;
        int64_t nb_tmp = out_sig->nb0[i];
        out_sig->nb0[i] = out_sig->nb1[i];
        out_sig->nb1[i] = nb_tmp;
    }
    uint8_t type_tmp = out_sig->src0_type;
    out_sig->src0_type = out_sig->src1_type;
    out_sig->src1_type = type_tmp;

    // Dst reshaped from [N×1] to [1×N].
    out_sig->ned[1] = 1;  // width becomes 1 — mmvf eligible

    *out_lc = lc_in;
    const ggml_tensor * tmp = out_lc->src0;
    out_lc->src0 = out_lc->src1;
    out_lc->src1 = tmp;

    *out_inverse_ctx = nullptr;  // identity writeback
    return 0;
}

static size_t transpose_weight_overhead(
    const ggml_hip_dispatch_signature_v1 &) {
    return 0;  // pure pointer swap, no allocation
}

// ---------------------------------------------------------------- BATCH_FOR_MMVF
static bool batch_for_mmvf_can_apply(
    const ggml_hip_dispatch_signature_v1 & sig) {
    if (sig.flags & GGML_HIP_SIG_HAS_IDS) return false;
    const bool is_float = sig.src0_type == GGML_TYPE_F32
                       || sig.src0_type == GGML_TYPE_F16
                       || sig.src0_type == GGML_TYPE_BF16;
    if (!is_float) return false;
    if (sig.src1_type != GGML_TYPE_F32) return false;
    const int64_t k = sig.ne0[0];
    if ((k % 2) != 0) return false;
    return sig.ned[1] > MMVF_MAX_BATCH_SIZE;
}

// Inverse context for batch iteration.
struct batch_inverse_ctx {
    int64_t total_n;               // original ned[1]
    int64_t batch_size;            // MMVF_MAX_BATCH_SIZE (or remainder)
    int64_t num_batches;
};

static int batch_for_mmvf_apply(
    const ggml_hip_dispatch_signature_v1 & orig_sig,
    ggml_hip_dispatch_signature_v1 * out_sig,
    ggml_hip_launch_context * out_lc,
    void ** out_inverse_ctx) {
    memcpy(out_sig, &orig_sig, sizeof(*out_sig));
    const int64_t total_n = orig_sig.ned[1];
    const int64_t batch_size = MMVF_MAX_BATCH_SIZE;
    const int64_t num_batches = (total_n + batch_size - 1) / batch_size;

    // Transformed sig: first batch only (representative).
    out_sig->ned[1] = std::min<int64_t>(batch_size, total_n);

    *out_lc = lc_in;
    // src1 and dst pointers stay the same — dispatch iterates from offset 0.

    // Inverse ctx tells dispatch how many batches to iterate.
    batch_inverse_ctx * bctx = new batch_inverse_ctx();
    bctx->total_n = total_n;
    bctx->batch_size = batch_size;
    bctx->num_batches = num_batches;
    *out_inverse_ctx = bctx;

    return 0;
}

static size_t batch_for_mmvf_overhead(
    const ggml_hip_dispatch_signature_v1 & sig) {
    // No temporary buffers — just pointer arithmetic in dispatch loop.
    return 0;
}

// ---------------------------------------------------------------- Registry
static const ggml_hip_routing_transformation s_transforms[] = {
    {
        GGML_HIP_TRANSFORM_TRANSPOSE_WEIGHT_FOR_MMVF,
        "transpose_weight_for_mmvf",
        GGML_HIP_SOURCE_PREDEFINED,
        true,   // equivalence_verified: AᵀB = (BᵀA)ᵀ for single-row A
        transpose_weight_overhead,
        transpose_weight_can_apply,
        transpose_weight_apply,
        nullptr  // identity writeback
    },
    {
        GGML_HIP_TRANSFORM_BATCH_FOR_MMVF,
        "batch_for_mmvf",
        GGML_HIP_SOURCE_PREDEFINED,
        true,   // equivalence_verified: matmul distributes over column partition
        batch_for_mmvf_overhead,
        batch_for_mmvf_can_apply,
        batch_for_mmvf_apply,
        nullptr  // writeback is identity — slices partition contiguous dst
    },
};

const ggml_hip_routing_transformation * ggml_hip_transform_find(
        ggml_hip_transform_id id) {
    for (int i = 0; i < sizeof(s_transforms)/sizeof(s_transforms[0]); ++i)
        if (s_transforms[i].id == id) return &s_transforms[i];
    return nullptr;
}

int ggml_hip_transform_count() {
    return sizeof(s_transforms)/sizeof(s_transforms[0]);
}

## TRANSPOSE_WEIGHT_FOR_MMVF

**Problem:** F32[1×K] × F32[K×N] where N > MMVF_MAX_BATCH_SIZE falls to BLAS because mmvf asserts `width <= MMVF_MAX_BATCH_SIZE`. But if we swap operands, the operation becomes F32[N×K]ᵀ × F32[K×1] which is a single-column matmul — mmvf with ne11=1, which is always eligible.

**Mathematical equivalence:** For matrices A (M×K) and B (K×N), the result C = AᵀB is N×M. When M=1, C is N×1. If we transpose to compute BᵀA (which gives K×M = K×1 intermediate, then multiply by N to get N×1), the result is:
- Original: C[i][0] = sum_k A[0][k] × B[k][i] for i in [0..N)
- Transposed: C'[j][0] = sum_k B[j][k] × A[0][k] for j in [0..N)

Since multiplication is commutative, C[i][0] == C'[i][0]. The result is **bit-identical**.

**Implementation:**
```c
// can_apply: F32 weight, single-row activation, width exceeds mmvf limit
static bool transpose_weight_can_apply(
    const ggml_hip_dispatch_signature_v1 & sig) {
    // Must be MUL_MAT (no IDS).
    if (sig.flags & GGML_HIP_SIG_HAS_IDS) return false;
    // Weight must be F32, single-row: ne0[1]==1 means M=1.
    if (sig.src0_type != GGML_TYPE_F32) return false;
    if (sig.ne0[1] != 1) return false;
    // Activation must be F32 (mmvf requirement).
    if (sig.src1_type != GGML_TYPE_F32) return false;
    // Width must exceed mmvf limit — otherwise mmvf already serves natively.
    const int64_t width = sig.ned[1];
    if (width <= MMVF_MAX_BATCH_SIZE) return false;
    return true;
}

// apply: swap src0↔src1, reshape dst from [N×1] to [1×N]
static int transpose_weight_apply(
    const ggml_hip_dispatch_signature_v1 & orig_sig,
    ggml_hip_dispatch_signature_v1 * out_sig,
    ggml_hip_launch_context * out_lc,
    void ** out_inverse_ctx) {
    memcpy(out_sig, &orig_sig, sizeof(*out_sig));

    // Swap src0 and src1 dimensions and types.
    int64_t ne_tmp[4];
    for (int i = 0; i < 4; ++i) {
        ne_tmp[i] = out_sig->ne0[i];
        out_sig->ne0[i] = out_sig->ne1[i];
        out_sig->ne1[i] = ne_tmp[i];
    }
    uint8_t type_tmp = out_sig->src0_type;
    out_sig->src0_type = out_sig->src1_type;  // F32 (was activation)
    out_sig->src1_type = type_tmp;            // F32 (was weight)

    // Swap strides too.
    for (int i = 0; i < 4; ++i) {
        int64_t nb_tmp = out_sig->nb0[i];
        out_sig->nb0[i] = out_sig->nb1[i];
        out_sig->nb1[i] = nb_tmp;
    }

    // Dst: original is [N×1], reshaped to [1×N]. ned[1] becomes 1.
    out_sig->ned[0] = orig_sig.ned[1];  // was N
    out_sig->ned[1] = 1;                 // was 1

    // Launch context: swap tensor pointers.
    *out_lc = lc_in;
    const ggml_tensor * tmp = out_lc->src0;
    out_lc->src0 = out_lc->src1;
    out_lc->src1 = tmp;

    // Inverse: identity — mmvf writes to same memory with stride interpretation.
    *out_inverse_ctx = nullptr;  // no writeback needed
    return 0;
}
```

## BATCH_FOR_MMVF

**Problem:** F32[M×K] × F32[K×N] where N > MMVF_MAX_BATCH_SIZE falls to BLAS. By splitting into ceil(N/8) batches of ≤8 columns each, every batch is mmvf-eligible.

**Mathematical equivalence:** C = AᵀB where B has N columns. If we split B into [B0 | B1 | ... | Bp] where each Bi has ≤8 columns, then:
- C = [AᵀB0 | AᵀB1 | ... | AᵀBp]

Each AᵀBi is an independent mmvf call. The result is **bit-identical** because matmul distributes over column partition.

**Implementation:**
```c
static bool batch_for_mmvf_can_apply(
    const ggml_hip_dispatch_signature_v1 & sig) {
    if (sig.flags & GGML_HIP_SIG_HAS_IDS) return false;
    const bool is_float = sig.src0_type == GGML_TYPE_F32
                       || sig.src0_type == GGML_TYPE_F16
                       || sig.src0_type == GGML_TYPE_BF16;
    if (!is_float) return false;
    if (sig.src1_type != GGML_TYPE_F32) return false;
    const int64_t k = sig.ne0[0];
    if ((k % 2) != 0) return false;  // mmvf requires k%2==0
    const int64_t width = sig.ned[1];
    if (width <= MMVF_MAX_BATCH_SIZE) return false;
    return true;
}
```

The `apply` function for batch transforms is **different from the model above**: it produces multiple launch contexts, not one. This requires a different API — instead of a single transformed sig/lc pair, it produces an array.

**Alternative approach (simpler):** Instead of making the transform produce multiple launch contexts at once, make each batch a separate "virtual dispatch". The tuner measures one representative batch (the first) and uses that timing × number_of_batches as the complete-path cost. At dispatch time, the dispatch layer iterates batches.

This is cleaner because:
1. The transform API stays simple: one in → one out
2. The tuner measures what it normally measures (one candidate per sig)
3. The overhead of batch iteration is included in the timing (we time the loop)

So BATCH_FOR_MMVF's `apply` produces a **single** transformed signature where ned[1] = min(orig_ned[1], MMVF_MAX_BATCH_SIZE), and the inverse_ctx carries the total N so dispatch knows to iterate.
