# bigcherry build's output directory ignores --llama-root

## Description

_build_dir(recipe, build) in __main__.py returns paths.REPO_ROOT / "build" / f"{recipe.name}-{build.name}" -- keyed only by recipe+build name, never by the --llama-root checkout being built. Two concurrent builds of the same recipe against different checkouts (e.g. a release_validate.py probe and a real build, or two probes) would write into and clobber the same build directory. Surfaced while finishing [[HI46]]/[[HI49]] -- release_validate.py's probe() deliberately does not attempt build-descriptor binary-scanning on top of this because doing so would encourage exactly the unsafe pattern this describes.
