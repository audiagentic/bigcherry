# HI17 quantitative native-repeatability parity closure

## Notes

The final review decision required an offline 12-cell reduction from the three existing Brutus artifacts. No new hardware run or HI17 code change was used. The reduction is checked in as HI17_BD4C552_PARITY_EVIDENCE.md.

## Findings

For every gfx1030/gfx1100/gfx1201 Sgemm, GemmEx, strided-batched, and pointer-batched cell, native and forced-native have 100 samples, complete p95/MAD data, and zero correctness error. Native cross-run median spread was calculated across R1/R2/R3. Each absolute forced/native median delta is <= max(5% declared noise tolerance, native spread). All 12 cells pass; the largest delta is 3.93% on gfx1100 strided in R2. The old large-K non-parity remains historical diagnostic evidence and is not the prescribed acceptance matrix.

## Conclusion

GO to close HI17. No additional runtime code change is warranted; HI24 native-twin work remains separate. The quantitative parity criterion is now satisfied and the no-promotion guard remains intact.
