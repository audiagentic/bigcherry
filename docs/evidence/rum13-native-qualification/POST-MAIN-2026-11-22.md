# Post-main native AQL regression evidence, 2026-11-22

This is a **model-independent laboratory** recheck against
native Radiance 2.2/ABI44 AQL with two gfx1100 cards and one gfx1201.
It does not execute the LTX C05 or C06 `RadCtx` graph.

| Devices | Existing row | BF16 exact result |
| --- | --- | --- |
| 3 distinct cards, gfx1100/gfx1100/gfx1201 | `ar_oneshot_3rank_exact_host` | 33/33; exit 0; ~0.41 s whole run |
| 3 distinct cards, gfx1100/gfx1100/gfx1201 | `ar_twoshot_3rank_exact_host` | 33/33; exit 0; ~0.41 s whole run |
| 3 ranks colocated on 1 gfx1201, ordinals 0/0/0 | `ar_oneshot_3rank_exact_host` | **timeout 124 at 40.02 s**, no complete numerical verdict |

The third experimental placement produced Radiance
**no-queue-progress** warnings identifying the wide one-shot
kernel after earlier Q/K cases had issued. The exact scheduling
mechanism is **not established**. Three spinning ranks on one
physical GPU are **not** the deployed mixed-card topology, so
this is not evidence of a mixed-card transport regression.
The shared RUM13 harness should refuse duplicate physical
device ordinals **before** launching a 3-rank independent-card
collective, rather than retrying a known-stalling control.
A homogeneous *single-device kernel* control is separate.

The short GPU lease was automatically released; `agent-lease status`
reported `gpu: free` and `rocm-smi --showpids` reported no remaining
KFD processes. No kernel or production engine source was modified.

Raw JSON and logs remain outside Git under the task's work root,
`ltx25-tp3-main-sync-aql/` (one file per row/devices/visible
case). Distinguish those whole-process elapsed times from native
per-step performance.

The separate 5-case source-backed LTX C01–C06 native CTest
passes. However it is a **host Builder declaration test**
and does **not** establish an issued model-backed C05 RMS or
C06 attention graph. LTX02 retains those acceptance gates.
