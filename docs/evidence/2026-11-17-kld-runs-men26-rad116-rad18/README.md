# KLD runs: men26, rad116, rad18 (result files)

The result files of three KLD runs, migrated from the work root so the runs can be deleted. The 3.9 GB recorded
reference logits of each run, and the failed attempt `rad116-kld/failed-1`, are not kept: they are only valid against
the pin and corpus they were recorded for and are regenerated by the next run (the policy is a fresh engine-local
reference per measurement).

| Run | What it measured | Decision record |
|---|---|---|
| `men26-kld` | Helper offload on the two XTX helpers against the R9700-alone control, 8,240 positions | `docs/planning/active/run-multi-engine/MEN26.md` |
| `rad116-kld` | Placement policy off, repeat and forced-churn arms against a BF16 reference | `docs/planning/active/patching-radiance-heat-placement/RHP22.md`, `RHP16.md` |
| `rad18-kld` | Combine off and on, bf16 row (failed) and fp16 row (passed) | `docs/planning/completed/patching-radiance-rdna3/RAD18.md`, `engines/radiance/patches/rad0008_hc_upmix_rt_sweep/SUMMARY.md` |

Contents per run: `kld*.json` and `*.kld.json.rows` (scored results), `run.json` (the run manifest), logs.
Absolute paths in the logs were replaced by placeholders: `<work-root>`, `<models-root>`, `<dev-root>`, `<data-root>`. Nothing
else was edited. Process ids, pid files, build directory pointers and symlinks were not migrated.
