## Verification performed before retirement (2026-11-27)

- **rad0062 anchor against the current pin.** The anchor block (`if(LQ_HIP_SRC)` / `target_compile_definitions(libquant PRIVATE LQ_CARD=1)` / `endif()`) is byte-identical between the lane's 1.x-era source snapshot and the pinned 2.2.0 source (`b6b8751`). The patch applies cleanly and idempotently to the 2.2.0 source with the repository patcher, and its hermetic tests (idempotence, missing-anchor refusal) pass. It remains `state = "untested"`: before any source may select it, quantizer code-object enumeration plus a synthetic and a full-recipe conversion on the conversion GPU are required.
- **CI gates for a future landing PR.** `core-offline-validation` does not run `tools/tests/lab` — the path filter triggers the workflow, but its run steps cover only the core/radiance/bench suites, the hardware screen, the ROCm SDK suite and the docs catalog. A live patch package additionally needs `docs/reference/engines/radiance/ENHANCEMENTS.md` regenerated by `tools/docs/generate_engine_enhancement_summaries.py` (docs-catalog gate), and the patch `SUMMARY.md` must carry `Summary`/`Outcome`/`Detail` headings (the branch version does not). Pull requests touching `engines/radiance/**` trigger the `radiance-build` gate, which applies and compiles the patch against the then-pinned source; `patch-compile-validation` is llamacpp-only.
- **Host-environment coupling.** `iq6r_v4_controller.py` and `iq6r_v4_convert_experimental.py` read `BC_WORK_ROOT`/`BC_RADIANCE_SOURCE`/`BC_RELEASE_MANIFEST`/`BC_MODEL_ROOT` at import time — the only lab tools in the repository that do. Five of the 15 lab test modules fail to import on hosts without those variables (46 of 51 tests pass without them); CI is unaffected. On resumption, move the reads into functions, as the rest of `tools/lab` does.
- **Forbidden terms.** The full branch delta (59 files plus commit messages, base `87d384d2c`) scanned clean against the local vocabulary with the repository scanner.
