# TR00 historical disposition evidence

This immutable bundle preserves the tooling disposition at RA01
implementation start. It contains exactly 383 unique rows recovered from
the historical disposition table at recovery source commit
`468e362c6ac8259c4cf2d585d72b9a757755ce92`, with provenance to the baseline
implementation-start commit `73068e9b4d1f612097f2efa582f046fd6013e11b`.

`TR00-baseline.json` is the normalized machine-readable capture. The Markdown
table is the human-readable snapshot. The maintained current registry lives
at `docs/reference/tooling/TOOL_DISPOSITION.md` and contains 385 rows; the
two RA39 lab rows are intentionally current-only and are not backfilled into
this historical evidence.

All files in this bundle are covered by `SHA256SUMS`.
