# IQ8R K-parallel register-spill removal — gfx1100

**Status:** resource, bit-identity and cold-timing gates passed. No serving or KLD run: outputs are bit-identical, so a decode ms/step A/B is a benefit measurement to take on the first release that carries the change.

## Change

In the existing libr3 native rewrite of `r4d_gemm_fp8a8.hip`, set the inner 128-K-unit loop's unroll count to 1 only for `SB==256 && NT>=2`; otherwise retain the full `kUG` count. Arithmetic, scale folding, KW, cross-wave reduction, memory layout and launch occupancy are unchanged. Vendor and gfx1201 are not edited.
