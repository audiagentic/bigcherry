# IQ6R-V4 timing and numerical comparison — step 3

- PASS: same attention tensor converted with the accelerated Hessian factoriser and the scalar fallback, each under an independent queued short lease on gfx1201.
- Accelerated wall time: 5.15 s. Scalar wall time: 463.61 s. Speed-up: 90.02x.
- Packed six-bit payload: 5,242,880 codes, zero changed; the five stored weight planes have identical SHA-256 hashes, bytes and bits, including scale and auxiliary planes.
- Both diagnostic containers were parsed by the container-inspection utility and are deliberately incomplete.
- Additional class-level timings were attempted but blocked by the shared GPU queue. The pending acquisition was cancelled before the lease was granted; no GPU work was performed by that attempt. Only the two completed weight-class timings are measured, and any other class estimate is an extrapolation.
- Full-model conversion and serving checks were not started.
