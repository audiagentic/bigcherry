# Experiments

Archived experiment code, kept so work can be picked up again. Nothing here is built, tested or shipped: each folder
holds `change.patch` (a diff against the recorded base commit) and a README with how to reapply it.
Outcomes and reasons: `docs/research/radiance-history/EXPERIMENT-REGISTER.md`. To revive one, branch from main, apply
the patch with `git apply --3way`, and take it through the normal PR and hardware gates.
